## **1.1. Cara Akses Master Data Varian**

**Berikut cara mengakses menu master data:**

1. Tekan menu Varian pada list menu sidebar kelola organisasi
   <Frame>
     ![ONLY ORGANISASI (sdqdqwe1ff)](/images/ONLY-ORGANISASI-\(sdqdqwe1ff\).png "ONLY ORGANISASI (sdqdqwe1ff)")
   </Frame>
2. Sistem akan menampilkan halaman **List Master Data Varian Produk**

## **1.2. Cara Menambah Varian Produk**

**Berikut cara menambah master data varian produk:**

1. Tekan tombol “Tambah varian” di halaman list varian produk
   <Frame>
     ![Fra6me 961 (1)](/images/Fra6me-961-\(1\).png "Fra6me 961 (1)")
   </Frame>
2. Setelah menekan tombol, maka akan menampilkan halaman input varian
3. Masukkan nama varian  di kolom nama varian
   <Frame>
     ![Input (sdfsfg3)](/images/Input-\(sdfsfg3\).png "Input (sdfsfg3)")
   </Frame>
4. Setelah selesai mengisi varian, kemudian tekan tombol “Simpan Varian”
   <Frame>
     ![Button (5sdfsewf)](/images/Button-\(5sdfsewf\).png "Button (5sdfsewf)")
   </Frame>
5. Setelah selesai menekan tombol, maka akan menampilkan halaman konfirmasi simpan varian produk
   <Frame>
     ![Alter Dialog (3ewerfwf)](/images/alter-dialog-\(3ewerfwf\).png "Alter Dialog (3ewerfwf)")
   </Frame>
6. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk menyimpan data  varian produk
   <Frame>
     ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
   </Frame>
7. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan 
   <Frame>
     ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
   </Frame>
8. Setelah tekan tombol “Ya, Saya Yakin”, maka akan menampilkan pesan sukses simpan varian

## **1.3. Cara Mengubah Varian Produk**

**Berikut cara mengubah master data varian produk:**

1. Tekan tombol “Edit varian” di halaman list varian produk
   <Frame>
     ![Button (2h473)](/images/Button-\(2h473\).png "Button (2h473)")
   </Frame>
2. Setelah menekan tombol, maka akan menampilkan halaman input varian
3. Ubah nama varian  di kolom nama varian
   <Frame>
     ![Input (sdfsfg3)](/images/Input-\(sdfsfg3\).png "Input (sdfsfg3)")
   </Frame>
4. Setelah selesai mengubah varian, kemudian tekan tombol “Simpan Varian”
   <Frame>
     ![Button (5sdfsewf)](/images/Button-\(5sdfsewf\).png "Button (5sdfsewf)")
   </Frame>
5. Setelah selesai menekan tombol, maka akan menampilkan halaman konfirmasi simpan varian produk
   <Frame>
     ![Alter Dialog (3ewerfwf)](/images/alter-dialog-\(3ewerfwf\).png "Alter Dialog (3ewerfwf)")
   </Frame>
6. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk menyimpan data  varian produk
   <Frame>
     ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
   </Frame>
7. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan 
   <Frame>
     ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
   </Frame>
8. Setelah tekan tombol “Ya, Saya Yakin”, maka akan menampilkan pesan sukses simpan varian
