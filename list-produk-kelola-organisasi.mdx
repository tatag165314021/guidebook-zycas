## 1.1. Cara Mengakses List Produk

**Berikut cara mengakses menu list produk:**

1. Tekan menu List Produk pada list menu di sidebar kelola organisasi

<Frame>
  ![ONLY ORGANISASI (21sxds)](/images/ONLY-ORGANISASI-\(21sxds\).png "ONLY ORGANISASI (21sxds)")
</Frame>

2. Setelah menekan menu List produk maka akan menampilkan halaman List Produk
3. Filter produk dengan status tertentu (aktif atau non aktif) di kolom filter status
   <Frame>
     ![Frame 34 (1)vgbv](/images/Frame-34-\(1\)vgbv.png "Frame 34 (1)vgbv")
   </Frame>
4. Filter produk dengan jumlah stok tertentu (stok hampir habis atau stok minus) di kolom filter jumlah stok
   <Frame>
     ![Frame 34 (2saw)](/images/Frame-34-\(2saw\).png "Frame 34 (2saw)")
   </Frame>
5. Cari produk dengan kata kunci tertentu di kolom cari
   <Frame>
     ![Input (28qaqa)](/images/Input-\(28qaqa\).png "Input (28qaqa)")
   </Frame>
6. Filter produk untuk toko tertentu di kolom filter toko
   <Frame>
     ![Inputfiltertoko](/images/Inputfiltertoko.png "Inputfiltertoko")
   </Frame>
