## **1.1. Cara Akses Ringkasan Penjualan**

**Berikut cara mengakses menu penjualan harian:**

1. Tekan menu Penjualan > Penjualan Harian pada list menu di menu sidebar kelola organisasi
   <Frame>
     ![ONLY ORGANISASI (17dsfsse)](/images/ONLY-ORGANISASI-\(17dsfsse\).png "ONLY ORGANISASI (17dsfsse)")
   </Frame>
2. Setelah menekan menu Penjualan Harian maka akan menampilkan halaman Penjualan Harian
3. Tekan tombol “Periode” untuk filter data laporan penjualan harian

<Frame>
  ![Input (2sdfsdfs6)](/images/Input-\(2sdfsdfs6\).png "Input (2sdfsdfs6)")
</Frame>

4. **Jika memilih filter mingguan klik tab “Mingguan”**

<Frame>
  ![Popover (5dfwedss)](/images/popover-\(5dfwedss\).png "Popover (5dfwedss)")
</Frame>

5. Pilih minggu dengan range tertentu
6. Setelah memilih minggu, tekan tombol “Terapkan Periode”
7. Setelah menekan tombol maka akan menampilkan data sesuai minggu di filter
8. **Jika memilih filter bulanan klik tab “Bulanan”**

<Frame>
  ![Popover (6dsfsdfa)](/images/popover-\(6dsfsdfa\).png "Popover (6dsfsdfa)")
</Frame>

9. Pilih bulan dengan range tertentu
10. Setelah memilih bulan, tekan tombol “Terapkan Periode”
11. Setelah menekan tombol maka akan menampilkan data sesuai bulan di filter
12. Tekan tombol “Nama Toko” untuk filter data laporan penjualan harian dari toko tertentu

<Frame>
  ![Inputfiltertoko](/images/Inputfiltertoko.png "Inputfiltertoko")
</Frame>
