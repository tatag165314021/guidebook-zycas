## **1.1. Cara Melakukan Registrasi dengan No Whatsapp**

Menu **Registrasi** adalah menu yang berisi form untuk mendaftarkan akun login di aplikasi Zycas. Untuk mengakses halaman ini adalah dengan klik Menu **Daftarkan Akun** di halaman login dan anda akan diarahkan ke halaman Registrasi

![Image](/images/image-1.png "Image")

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Nama | Kolom untuk mengisi nama pengguna |
| 2 | No Whatsapp | Kolom untuk mengisi no whatsapp pengguna |
| 3 | Password | Kolom untuk mengisi password pengguna |
| 4 | Verifikasi Password | Kolom untuk mengisi verifikasi password |
| 5 | Nama Toko | Kolom untuk mengisi nama toko |
| 6 | Jenis Toko | Kolom untuk mengisi jenis toko |
| 7 | Alamat | Kolom untuk mengisi alamat toko |
| 8 | Persetujuan Kebijakan Privacy | Kolom untuk menyetujui kebijakan privacy |
| 9 | Persetujuan Disclaimer Pengguna | Kolom untuk persetujuan disclaimer pengguna |
| 10 | Daftarkan Akun dan Toko | Tombol untuk memproses pendaftaran akun pengguna |
| 11 | kembali ke Login | Tombol untuk kembali ke halaman login |

**Berikut merupakan tahapan registrasi akun:**

1. Tekan tombol "Buat dengan No Whatsapp" di opsi metode registrasi

![Image](/images/image-2.png "Image")

2. Setelah menekan tombol, maka akan diarahkan ke form registrasi
3. Masukkan nama lengkap anda di kolom nama

![Image](/images/image-4.png "Image")

4. Masukkan no whatsapp anda di kolom no whatsapp dengan _contoh: 085869726331_

![Image](/images/image-5.png "Image")

5. Masukkan password anda di kolom password. Buat password yang kuat dengan kombinasi huruf kapital, angka dan simbol

![Image](/images/image-6.png "Image")

6. Masukkan ulang password anda di kolom verifikasi password

![Image](/images/image-7.png "Image")

7. Masukkan nama toko di kolom nama toko

![Image](/images/image-8.png "Image")

8. Tekan tombol “Jenis Toko” untuk memilih jenis toko

![Image](/images/image-9.png "Image")

9. Setelah menekan tombol, maka akan menampilkan halaman list jenis toko

![Image](/images/image-10.png "Image")

10. Pilih salah satu jenis toko

![Image](/images/image-11.png "Image")

11. Atau masukkan jenis toko lain di kolom jenis toko lain-lain jika tidak tersedia pada pilihan

![Image](/images/image-12.png "Image")

12. Setelah selesai menentukan jenis toko, kemudian tekan tombol “Pilih Jenis Lain-lain”

![Image](/images/image-13.png "Image")

13. Setelah memilih jenis toko, maka akan menampilkan jenis toko di halaman buat toko

![Image](/images/image-14.png "Image")

14. Masukkan alamat toko yang terdaftar di Google Maps di kolom alamat toko

![Image](/images/image-15.png "Image")

15. Checklist persetujuan kebijakan privacy

![Image](/images/image-16.png "Image")

| **🛈Information** | Baca kebijakan privacy terlebih dahulu sebelum checklist |
| :-: | :-- |

16. Checklist persetujuan ketentuan penggunaan aplikasi

![Image](/images/image-17.png "Image")

| **🛈 Information** | Baca disclaimer pengguna terlebih dahulu sebelum checklist |
| :-: | :-- |

17. Setelah selesai mengisi data registrasi, kemudian tekan tombol “Daftarkan Akun dan Toko”

![Image](/images/image-18.png "Image")

18. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi registrasi

![Image](/images/image-20.png "Image")

19. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk melanjutkan registrasi

<img
  src="/images/image-21.png"
  alt="Image"
  title="Image"
  style={{ width:"27%" }}
/>

20. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan registrasi

<img
  src="/images/image-22.png"
  alt="Image"
  title="Image"
  style={{ width:"21%" }}
/>

21. Setelah menekan tombol “Ya, Saya Yakin”, maka akan menampilkan halaman Konfirmasi OTP

![Image](/images/image-23.png "Image")

22. Masukkan kode otp sesuai dengan kode yang dikirimkan di no whatsapp anda

![Image](/images/image-24.png "Image")

23. Setelah selesai mengisi kode otp, kemudian tekan tombol “Konfirmasi OTP”

![Image](/images/image-25.png "Image")

24. Setelah menekan tombol “Konfirmasi OTP”, jika kode otp benar, maka akan menampilkan pesan sukses dan diarahkan ke halaman enroll untuk masuk dengan akun owner anda

![Image](/images/image-26.png "Image")

25. Pilih akun untuk masuk ke dashboard Zycas di kolom pilih akun yang akan masuk

![Image](/images/image-27.png "Image")

26. Masukkan password sesuai akun yang anda pilih di kolom password

![Image](/images/image-28.png "Image")

27. Tekan tombol "Menuju Dashboard"

![Image](/images/image-29.png "Image")

28. Setelah menekan tombol, jika password benar maka akan diarahkan ke halaman dashboard

![Image](/images/image-30.png "Image")
