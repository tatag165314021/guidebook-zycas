## **1.1. Cara Mengakses List Hutang**

**Berikut cara mengakses halaman list hutang:** 

1. Tekan menu Laporan Hutang pada list menu di sidebar kelola organisasi

<Frame>
  ![FULL (3vddfbht)](/images/FULL-\(3vddfbht\).png "FULL (3vddfbht)")
</Frame>

2. Setelah menekan menu Laporan Hutang maka akan menampilkan halaman List Hutang
3. Masukkan kata kunci tertentu di kolom cari untuk mencari data laporan hutang dengan cepat

<Frame>
  ![Input (20ddfsdf)](/images/Input-\(20ddfsdf\).png "Input (20ddfsdf)")
</Frame>

4. Tekan tombol "Detail Transaksi" untuk mengakses halaman detail transaksi hutang

<Frame>
  ![Button (1qa7)](/images/Button-\(1qa7\).png "Button (1qa7)")
</Frame>
