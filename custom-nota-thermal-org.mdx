## **1.2. Cara Membuat Template Nota Thermal**

**Berikut cara membuat template nota thermal:**

1. Tekan tombol "Custom Struk Thermal"

<Frame>
  ![Frame 237za939](/images/Frame-237za939.png "Frame 237za939")
</Frame>

<Frame>
  ![Tambah Vouchesfwerwcfr](/images/Tambah-Vouchesfwerwcfr.jpg "Tambah Vouchesfwerwcfr")

<Frame>
  ![Inpuu9iyyuy7ut](/images/Inpuu9iyyuy7ut.png "Inpuu9iyyuy7ut")
</Frame>

4. Pilih layout template di kolom Pilih layout yang akan Anda digunakan

<Frame>
  ![Frame 238389awa](/images/Frame-238389awa.png "Frame 238389awa")
</Frame>

<Frame>
  ![Inpuffvtt](/images/Inpuffvtt.png "Inpuffvtt")
</Frame>

<Frame>
  ![Botto35dm](/images/botto35dm.png "Botto35dm")
</Frame>

9. Pilih variabel nota di kolom bentuk isi

23. Tekan tombol "Tambah Isi Header" atau "Tambah Isi Footer" untuk menambahkan kolom pengisian variabel nota

<Frame>
  ![Buttonrd6t](/images/Buttonrd6t.png "Buttonrd6t")
</Frame>

24. Tekan tombol "Hapus" untuk menghapus salah satu variabel baris atau kolom template custom nota

<Frame>
  ![Button6t6r4f](/images/Button6t6r4f.png "Button6t6r4f")
</Frame>

25. Tekan tombol "Kosongkan Isi Header" atau "Kosongkan Isi Footer" untuk mengembalikan data ke sebelum diubah

<Frame>
  ![Buttonewfwt45fre](/images/Buttonewfwt45fre.png "Buttonewfwt45fre")
</Frame>

26. Sebelum simpan template layout nota thermal, lihat hasil pengisian variabel apakah sudah sesuai di bagian kanan terdapat live preview template
27. Tekan tombol "Simpan Template Struk Thermal"

<Frame>
  ![Frame 237856d2q](/images/Frame-237856d2q.png "Frame 237856d2q")
</Frame>

27. Setelah menekan tombol, maka akan menampilkan pop up konfirmasi simpan template

<Frame>
  ![Alter Dialog44dw35](/images/alter-dialog44dw35.png "Alter Dialog44dw35")
</Frame>

28. Tekan tombol "Tidak" untuk membatalkan pembuatan template nota

<Frame>
  ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
</Frame>

29. Tekan tombol "Ya, Saya Yakin" untuk memproses pembuatan template nota

<Frame>
  ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
</Frame>

30. Setelah menekan tombol, maka akan menampilkan pesan sukses simpan template nota
