Pada halaman awal setelah membuka aplikasi, jika anda belum login & device belum terkunci, maka anda akan dihadapkan dengan form login. Lakukan registrasi untuk dapat login di aplikasi Zycas dan mulai pencatatan transaksi anda.

<Frame>
  ![Registrasi 1](/images/registrasi-1.png "Registrasi 1")
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | No Whatsapp | Kolom untuk mengisi no whatsapp pengguna ketika login |
| 2 | Password | Kolom untuk mengisi password pengguna ketika login |
| 3 | Masuk | Tombol untuk login aplikasi |
| 4 | Daftarkan Akun | Tombol untuk melakukan registrasi akun |
| 5 | Reset Password | Tombol jika lupa password pengguna |

## **1.1. Cara Melakukan Registrasi**

Menu **Registrasi** adalah menu yang berisi form untuk mendaftarkan akun login di aplikasi Zycas. Untuk mengakses halaman ini adalah dengan klik Menu **Daftarkan Akun** di halaman login dan anda akan diarahkan ke halaman Registrasi

<Frame>
  ![Registrasi 2](/images/registrasi-2.png "Registrasi 2")
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Nama | Kolom untuk mengisi nama pengguna |
| 2 | No Whatsapp | Kolom untuk mengisi no whatsapp pengguna |
| 3 | Password | Kolom untuk mengisi password pengguna |
| 4 | Verifikasi Password | Kolom untuk mengisi verifikasi password |
| 5 | Persetujuan Kebijakan Privacy | Kolom untuk menyetujui kebijakan privacy |
| 6 | Persetujuan Disclaimer Pengguna | Kolom untuk persetujuan disclaimer pengguna |
| 7 | Daftarkan Akun | Tombol untuk memproses pendaftaran akun pengguna |
| 8 | kembali ke Login | Tombol untuk kembali ke halaman login |

**Berikut merupakan tahapan registrasi akun:**

1. Masukkan nama lengkap anda di kolom nama

<Frame>
  ![Input Nama Registrasi](/images/input-nama-registrasi.png "Input Nama Registrasi")
</Frame>

2. Masukkan no whatsapp anda di kolom no whatsapp dengan _contoh: 085869726331_

<Frame>
  ![Input Whatsapp Registrasi](/images/input-whatsapp-registrasi.png "Input Whatsapp Registrasi")
</Frame>

3. Masukkan password anda di kolom password. Buat password yang kuat dengan kombinasi huruf kapital, angka dan simbol

<Frame>
  ![Input Password Registrasi](/images/input-password-registrasi.png "Input Password Registrasi")
</Frame>

4. Masukkan ulang password anda di kolom verifikasi password

<Frame>
  ![Input Veri Password Registrasi](/images/input-veri-password-registrasi.png "Input Veri Password Registrasi")
</Frame>

5. Checklist persetujuan kebijakan privacy

<Frame>
  ![Checklist Registrasi 1](/images/checklist-registrasi-1.png "Checklist Registrasi 1")
</Frame>

| **🛈Information** | Baca kebijakan privacy terlebih dahulu sebelum checklist |
| :-: | :-- |

6. Checklist persetujuan ketentuan penggunaan aplikasi

<Frame>
  ![Checklist Registrasi 2](/images/checklist-registrasi-2.png "Checklist Registrasi 2")
</Frame>

| **🛈Information** | Baca disclaimer pengguna terlebih dahulu sebelum checklist |
| :-: | :-- |

7. Setelah selesai mengisi data registrasi, kemudian tekan tombol “Daftarkan Akun”

<Frame>
  ![Tombol Registrasi 3](/images/tombol-registrasi-3.png "Tombol Registrasi 3")
</Frame>

8. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi registrasi

<Frame>
  ![Pop Up Konfirmasi Registrasi](/images/pop-up-konfirmasi-registrasi.png "Pop Up Konfirmasi Registrasi")
</Frame>

9. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk melanjutkan registrasi

<Frame>
  ![Tombol Ya Saya Yakin Registrasi](/images/tombol-ya-saya-yakin-registrasi.png "Tombol Ya Saya Yakin Registrasi")
</Frame>

10. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan registrasi

<Frame>
  ![Tombol Tidak Registrasi](/images/tombol-tidak-registrasi.png "Tombol Tidak Registrasi")
</Frame>

11. Setelah menekan tombol “Ya, Saya Yakin”, maka akan menampilkan halaman Konfirmasi OTP

<Frame>
  ![Input Otp Registrasi](/images/input-otp-registrasi.png "Input Otp Registrasi")
</Frame>

12. Masukkan kode otp sesuai dengan kode yang dikirimkan di no whatsapp anda

<Frame>
  ![Input Nomor Otp Registrasi](/images/input-nomor-otp-registrasi.png "Input Nomor Otp Registrasi")

13. Setelah selesai mengisi kode otp, kemudian tekan tombol “Konfirmasi OTP”

</Frame>
