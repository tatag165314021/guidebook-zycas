**Berikut merupakan tahapan registrasi akun:**

1. Tekan tombol "Buat dengan No Whatsapp" di opsi metode registrasi

<Frame>
  ![Alter Dialog (18ereret)](/images/alter-dialog-\(18ereret\).png "Alter Dialog (18ereret)")
</Frame>

2. Setelah menekan tombol, maka akan diarahkan ke form registrasi
3. Masukkan nama lengkap anda di kolom nama

<Frame>
  ![Nama Anda (1)sfsdff](/images/Nama-Anda-\(1\)sfsdff.png "Nama Anda (1)sfsdff")
</Frame>

4. Masukkan no whatsapp anda di kolom no whatsapp dengan _contoh: 085869726331_

<Frame>
  ![Input76g6](/images/Input76g6.png "Input76g6")
</Frame>

5. Masukkan password anda di kolom password. Buat password yang kuat dengan kombinasi huruf kapital, angka dan simbol

<Frame>
  ![Password](/images/Password.png "Password")
</Frame>

6. Masukkan ulang password anda di kolom verifikasi password

<Frame>
  ![Verifikasi Passwordsdfsdfsf](/images/Verifikasi-Passwordsdfsdfsf.png "Verifikasi Passwordsdfsdfsf")
</Frame>

7. Masukkan nama toko di kolom nama toko

<Frame>
  ![Input (7wrs)](/images/Input-\(7wrs\).png "Input (7wrs)")
</Frame>

8. Tekan tombol “Jenis Toko” untuk memilih jenis toko

<Frame>
  ![Input (uj9)](/images/Input-\(uj9\).png "Input (uj9)")
</Frame>

9. Setelah menekan tombol, maka akan menampilkan halaman list jenis toko
10. Pilih salah satu jenis toko
11. Atau masukkan jenis toko lain di kolom jenis toko lain-lain jika tidak tersedia pada pilihan

<Frame>
  ![Jenis Lainnydsfda](/images/Jenis-Lainnydsfda.png "Jenis Lainnydsfda")
</Frame>

12. Masukkan alamat toko yang terdaftar di Google Maps di kolom alamat toko

<Frame>
  ![Alamat Tokowerwer](/images/Alamat-Tokowerwer.png "Alamat Tokowerwer")
</Frame>

13. Checklist persetujuan kebijakan privacy

  ![Checkbogfgfrx](/images/checkbogfgfrx.png "Checkbogfgfrx")

15. Setelah selesai mengisi data registrasi, kemudian tekan tombol “Daftarkan Akun dan Toko”

<Frame>
  ![Button (28)sdfsse](/images/Button-\(28\)sdfsse.png "Button (28)sdfsse")
</Frame>

16. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi registrasi

<Frame>
  ![Alter Dialog (1fdfer9)](/images/alter-dialog-\(1fdfer9\).png "Alter Dialog (1fdfer9)")
</Frame>

17. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk melanjutkan registrasi

<Frame>
  ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
</Frame>

18. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan registrasi

<Frame>
  ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
</Frame>

19. Setelah menekan tombol “Ya, Saya Yakin”, jika data registrasi valid maka akan menampilkan halaman Konfirmasi OTP

<Frame>
  ![OT Pdds](/images/OTPdds.png "OT Pdds")
</Frame>

20. Masukkan kode otp sesuai dengan kode yang dikirimkan di no whatsapp anda

<Frame>
  ![Component 26sdfr](/images/Component-26sdfr.png "Component 26sdfr")
</Frame>

21. Setelah selesai mengisi kode otp, kemudian tekan tombol “Konfirmasi OTP”

<Frame>
  ![Button (2sdfert9)](/images/Button-\(2sdfert9\).png "Button (2sdfert9)")
</Frame>

22. Setelah menekan tombol, jika data valid maka akan menampilkan halaman list organisasi

      ![Home](/images/Home.jpg "Home")
    </Frame>
