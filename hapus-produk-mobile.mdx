## 1.1. Cara Menghapus Produk

Menu Hapus Produk adalah menu yang dapat digunakan untuk menghapus data produk dari list. Untuk mengakses halaman ini adalah dengan klik tombol “Hapus Produk” di halaman list produk

**Berikut Cara Menghapus Produk:**

1. Tekan tombol Hapus di salah satu produk/varian di list produk
   <Frame>
     ![Button6t6r4f](/images/Button6t6r4f.png "Button6t6r4f")
   </Frame>
2. Setelah menekan tombol, maka akan menampilkan pop up konfirmasi hapus produk
   <Frame>
     ![Frame 1205 (4sasczc)](/images/Frame-1205-\(4sasczc\).png "Frame 1205 (4sasczc)")
   </Frame>
3. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk melanjutkan proses hapus produk/varian
   <Frame>
     ![Button 45e(11)](/images/Button-45e\(11\).png "Button 45e(11)")
   </Frame>
4. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan hapus produk/varian
   <Frame>
     ![Frame 1365ssssa](/images/Frame-1365ssssa.png "Frame 1365ssssa")
   </Frame>
5. Setelah menekan tombol “Ya, Saya Yakin”,  maka akan mengarahkan ke halaman halaman list produk dan produk akan terhapus dari list produk
