## **1.1. Cara Akses List Transaksi**

**Berikut cara mengakses menu transaksi:**

1. Tekan menu List Transaksi pada list menu di sidebar kelola toko

<Frame>
  ![FUL Lgjrthfr](/images/FULLgjrthfr.png "FUL Lgjrthfr")
</Frame>

2. Setelah menekan menu List Transaksi maka akan menampilkan halaman List Transaksi
3. Pilih status transaksi tertentu di kolom filter status transaksi untuk melihat riwayat transaksi pada status tertentu

<Frame>
  ![Input (14wewsaw)](/images/Input-\(14wewsaw\).png "Input (14wewsaw)")
</Frame>

4. Pilih tanggal transaksi tertentu di kolom filter tanggal transaksi untuk melihat riwayat transaksi pada tanggal tertentu

<Frame>
  ![Input (15ruws)](/images/Input-\(15ruws\).png "Input (15ruws)")
</Frame>

6. Tekan tombol detail pada halaman list transaksi

<Frame>
  ![Button (23werwerw)](/images/Button-\(23werwerw\).png "Button (23werwerw)")
</Frame>

7. Setelah menekan tombol, maka akan menampilkan halaman detail transaksi

## **1.2. Cara Mencetak Nota Transaksi**

**Berikut cara mengakses menu Cetak Nota Transaksi:**

1. Tekan tombol “Simpan PDF” di halaman detail transaksi
   <Frame>
     ![Button (24sweweds)](/images/Button-\(24sweweds\).png "Button (24sweweds)")
   </Frame>
2. Setelah menekan tombol, maka akan mencetak nota transaksi pdf. Dokumen nota pdf bisa diakses di penyimpanan internal perangkat anda
   <Frame>
     ![Hasil Download PDF](/images/Hasil-download-PDF.png "Hasil Download PDF")
   </Frame>

## **1.3. Cara Melihat Riwayat Retur Produk**

**Berikut cara mengakses menu Riwayat Retur Produk:**

1. Tekan tombol “List Barang Retur” di halaman detail transaksi
   <Frame>
     ![Button (25eqwe23das)](/images/Button-\(25eqwe23das\).png "Button (25eqwe23das)")
   </Frame>
2. Setelah menekan tombol, maka akan menampilkan halaman riwayat retur produk
   <Frame>
     ![Alter Dialog (16erwedwx)](/images/alter-dialog-\(16erwedwx\).png "Alter Dialog (16erwedwx)")
   </Frame>
