## **1.1. Cara Melakukan Reset Password Owner**

Menu **Reset Password** adalah menu yang berisi form untuk lupa password di aplikasi Zycas untuk user owner.

<Frame>
  ![Lupa Paessword](/images/Lupa-Paessword.jpg "Lupa Paessword")
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | No Whatsapp | Kolom untuk mengisi no whatsapp pengguna |
| 2 | Kirim Permintaan | Tombol untuk memproses reset password |
| 3 | Kembali ke Login | Tombol untuk kembali ke halaman login |

**Berikut merupakan tahapan reset password:**

1. Pilih tab “Owner” di halaman login
   <Frame>
     ![Bottoswm](/images/bottoswm.png "Bottoswm")
   </Frame>
2. Tekan tombol “Lupa Password”
   <Frame>
     ![Buttonw2 (5)](/images/Buttonw2-\(5\).png "Buttonw2 (5)")
   </Frame>
3. Setelah menekan tombol, maka akan menampilkan halaman lupa password
4. Masukkan no whatsapp anda di kolom no whatsapp
   <Frame>
     ![WA](/images/WA.png "WA")
   </Frame>
5. Setelah selesai mengisi data no whatsapp, kemudian tekan tombol “Kirim Permintaan”
   <Frame>
     ![Button (s24)](/images/Button-\(s24\).png "Button (s24)")
   </Frame>
6. Setelah menekan tombol, maka akan menampilkan halaman pengisian OTP

![O Tw P](/images/OTwP.png "O Tw P")

7. Masukkan kode otp sesuai dengan kode yang dikirimkan di no whatsapp anda

![Componeswnt 26](/images/Componeswnt-26.png "Componeswnt 26")

8. Tekan tombol "Konfirmasi OTP"

![Butseton (6)](/images/Butseton-\(6\).png "Butseton (6)")

9. Setelah mengisi kode otp, jika kode otp benar, maka akan menampilkan pesan sukses reset password dan diarahkan ke halaman login, informasi password akan dikirim ke no whatsapp user
