**Berikut merupakan cara menambahkan toko**

1. Setelah login dan memilih masuk ke menu kelola toko maka akan menampilkan halaman list toko (lihat panduan login owner/employee)
   <Frame>
     ![Linkesw2d Device](/images/Linkesw2d-Device.jpg "Linkesw2d Device")
   </Frame>
2. Tekan tombol “Tambah Toko”
   <Frame>
     ![Butt57on (13)](/images/Butt57on-\(13\).png "Butt57on (13)")
   </Frame>
3. Setelah menekan tombol, maka akan menampilkan halaman form tambah toko
4. Masukkan nama toko di kolom nama toko
   <Frame>
     ![Input (7wrs)](/images/Input-\(7wrs\).png "Input (7wrs)")
   </Frame>
5. Tekan tombol “Tipe Toko” untuk memilih tipe toko
6. Tekan tombol “Jenis Toko” untuk memilih jenis toko
   <Frame>
     ![Input (uj9)](/images/Input-\(uj9\).png "Input (uj9)")
   </Frame>
7. Masukkan alamat toko di kolom alamat
   <Frame>
     ![Inpuvbt (12)](/images/Inpuvbt-\(12\).png "Inpuvbt (12)")
   </Frame>
8. Masukkan no whatsapp toko di kolom no whatsapp
   <Frame>
     ![WA](/images/WA.png "WA")
   </Frame>
9. Tekan tombol “Lokasi” untuk memilih lokasi toko
10. Setelah menekan tombol, maka akan menampilkan halaman input lokasi
11. Pasang pin lokasi sesuai koordinat toko
12. Setelah selesai memasang pin lokasi, kemudian tekan tombol “Pilih Lokasi”
13. Setelah menekan tombol, maka akan menampilkan koordinat lokasi di halaman buat toko
14. Setelah selesai mengisi data toko, kemudian tekan tombol “Simpan Toko”
    <Frame>
      ![Button (1q2)](/images/Button-\(1q2\).png "Button (1q2)")
    </Frame>
15. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi simpan toko
    <Frame>
      ![Alter Dialo1g (7)](/images/alter-dialo1g-\(7\).png "Alter Dialo1g (7)")
    </Frame>
16. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk simpan toko
    <Frame>
      ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
    </Frame>
17. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan simpan toko
    <Frame>
      ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
    </Frame>
18. Setelah menekan tombol “Ya, Saya Yakin”, maka akan menampilkan pesan sukses membuat toko dan diarahkan ke halaman list toko
