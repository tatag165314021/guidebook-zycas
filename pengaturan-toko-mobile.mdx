## **1.2. Cara Mengubah Persen Pajak**

**Berikut cara mengakses menu edit pajak:**

1. Tekan tombol “Edit Pajak” di halaman Pengaturan Toko

<Frame>
  ![Framesdwe 6](/images/Framesdwe-6.png "Framesdwe 6")
</Frame>

2. Setelah menekan tombol, maka akan menampilkan halaman ubah pajak

<Frame>
  <img
    src="/images/Frame-13ww36-(3).png"
    alt="Frame 13ww36 (3)"
    title="Frame 13ww36 (3)"
    style={{ width:"41%" }}
  />
</Frame>

3. Ubah persen pajak di kolom persen pajak

<Frame>
  ![Fraqme 1457](/images/Fraqme-1457.png "Fraqme 1457")

## **1.5. Cara Mengaktifkan Metode Pembayaran**

**Berikut cara mengakses menu metode pembayaran:**

1. Gulirkan layar kebawah di halaman master data untuk melihat metode pembayaran yang aktif di halaman Pengaturan Toko

<Frame>
  ![Frame 158s9](/images/Frame-158s9.png "Frame 158s9")
</Frame>

2. Tekan tombol “Tunai” untuk dapat mengaktifkan metode pembayaran tunai
3. Tekan tombol “Debit/Kredit” untuk dapat mengaktifkan metode pembayaran debit/kredit
4. Tekan tombol “Voucher” untuk dapat mengaktifkan metode pembayaran voucher
5. Tekan tombol “Hutang” untuk dapat mengaktifkan metode pembayaran hutang
6. Tekan tombol “QRIS” untuk dapat mengaktifkan metode pembayaran QRIS
7. Unggah gambar kode QRIS dengan tekan tombol “Unggah QRIS”

<Frame>
  ![Framwwe 6](/images/Framwwe-6.png "Framwwe 6")
</Frame>

## **1.7. Cara Mengunggah Logo Toko**

**Berikut cara mengunggah logo toko:**

1. Tekan tombol “Unggah Gambar” untuk mengganti gambar logo toko di halaman Pengaturan Toko

<Frame>
  ![Frzzame 1409](/images/Frzzame-1409.png "Frzzame 1409")
</Frame>

2. Setelah menekan tombol maka pilih gambar logo pada perangkat anda
3. Setelah memilih gambar logo maka logo toko berhasil diunggah di aplikasi Zycas

| **🛈Information** | Unggah logo maksimal 1 MB dan rasio 1000 x 1000 px dengan tipe file .jpg, .png, .jpeg dan .svg |
