## **1.1. Cara Akses Bind Device**

**Berikut cara mengakses halaman dashboard:** 

1. Tekan menu device tertaut di sidebar menu kelola toko
   <Frame>
     <img
       src="/images/FUL12wL.png"
       alt="Ful12w L"
       title="Ful12w L"
       className="mr-auto"
       style={{ width:"44%" }}
     />
   </Frame>
2. Setelah menekan tombol, maka akan menampilkan halaman bind device
3. **Ganti konteks toko**
4. Tekan tombol "Toko" di pojok kanan atas halaman
   <Frame>
     ![Nasevbar](/images/Nasevbar.png "Nasevbar")
   </Frame>
5. Setelah menekan tombol, maka akan menampilkan list toko
   <Frame>
     ![Frame2 34](/images/Frame2-34.png "Frame2 34")
   </Frame>
6. Pilih salah satu toko
7. Setelah memilih salah satu toko maka akan menampilkan list device tertaut di toko tersebut

## **1.2. Cara Lepas Tautan Bind Device**

**Berikut cara mengakses halaman dashboard:** 

1. Tekan tombol “Lepas Tautan” di halaman list device tertaut untuk melepas perangkat yang tertaut dengan akun zycas mobile
   <Frame>
     ![Sect356ion (5)](/images/Sect356ion-\(5\).png "Sect356ion (5)")
   </Frame>
2. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi lepas perangkat
   <Frame>
     ![Alter Dia2swlog (8)](/images/alter-dia2swlog-\(8\).png "Alter Dia2swlog (8)")
   </Frame>
3. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk melanjutkan lepas perangkat
   <Frame>
     ![Button 45e(11)](/images/Button-45e\(11\).png "Button 45e(11)")
   </Frame>
4. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan lepas perangkat
   <Frame>
     ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
   </Frame>
5. Setelah menekan tombol “Ya, Saya Yakin”,  maka akan menampilkan halaman list device tertaut serta notifikasi “Device telah berhasil dilepas tautannya”
