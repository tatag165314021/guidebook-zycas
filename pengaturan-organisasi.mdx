## **1.1. Cara Akses Pengaturan Organisasi**

**Berikut cara mengakses menu organisasi:**

1. Tekan Pengaturan di menu sidebar kelola organisasi
   <Frame>
     ![Frame Saw53](/images/Frame-saw53.png "Frame Saw53")
   </Frame>
2. Setelah menekan menu Pengaturan maka akan menampilkan halaman Pengaturan Organisasi

## **1.2. Cara Edit Organisasi**

**Berikut cara edit organisasi:**

1. Tekan tombol “Ubah Organisasi” dengan icon pensil di halaman pengaturan organisasi untuk memulai proses mengubah data organisasi
   <Frame>
     ![Frame 237939a](/images/Frame-237939a.png "Frame 237939a")
   </Frame>
2. Setelah menekan tombol, maka akan menampilkan halaman ubah organisasi
3. Ubah logo organisasi di kolom unggah logo

<Frame>
  ![Inputgvr22](/images/Inputgvr22.png "Inputgvr22")
</Frame>

4. Ubah nama organisasi di kolom nama organisasi

<Frame>
  ![Inputw23e](/images/Inputw23e.png "Inputw23e")
</Frame>

5. Ubah no whatsapp organisasi di kolom no whatsapp

<Frame>
  ![Input76g6](/images/Input76g6.png "Input76g6")
</Frame>

6. Ubah email organisasi di kolom email

<Frame>
  ![Input69ujo](/images/Input69ujo.png "Input69ujo")
</Frame>

7. Ubah nomor induk berusaha di kolom siup/nib

<Frame>
  ![Input7h96g](/images/Input7h96g.png "Input7h96g")
</Frame>

8. Ubah npwp organisasi di kolom npwp

<Frame>
  ![Inputvdgb](/images/Inputvdgb.png "Inputvdgb")
</Frame>

9. Tekan tombol "Reset" untuk mengembalikan data ke sebelum diubah

<Frame>
  ![Buretseestton](/images/Buretseestton.png "Buretseestton")
</Frame>

10. Setelah selesai mengubah data organisasi, kemudian tekan tombol “Simpan Organisasi”

<Frame>
  ![Buttonu3492e](/images/Buttonu3492e.png "Buttonu3492e")
</Frame>

11. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi simpan organisasi

<Frame>
  ![Alter Dialoge3e42](/images/alter-dialoge3e42.png "Alter Dialoge3e42")
</Frame>

12. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk simpan organisasi

<Frame>
  ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
</Frame>

13. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan simpan organisasi

<Frame>
  ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
</Frame>

14. Setelah menekan tombol “Ya, Saya Yakin”, maka akan menampilkan pesan sukses membuat organisasi
