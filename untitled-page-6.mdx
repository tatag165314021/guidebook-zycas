Fitur Voucher pada aplikasi Zycas berguna untuk mengelola atau mengatur voucher mulai dari menambah voucher baru  dan mengedit voucher yang telah terdaftar pada sistem. Voucher nantinya dapat digunakan sebagai potongan pembayaran atau pemberian produk gratis ketika melakukan transaksi.

<Frame>
  ![Image](/images/image-2823.png)
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Tambah Voucher | Tombol untuk menambahkan voucher |
| 2 | Status Voucher | Tombol untuk filter status voucher |
| 3 | Jangka waktu Voucher | Tombol untuk filter jangka waktu voucher |
| 4 | Pencarian Voucher | Tombol untuk pencarian voucher |
| 5 | Filter Toko | Tombol untuk filter data voucher di toko tertentu |
| 6 | Edit voucher | Tombol untuk edit voucher |
| 7 | Detail Voucher | Tombol untuk mengakses detail voucher |

## **1.2. Cara Menambah Voucher Baru**

Tambah Voucher adalah fitur yang berfungsi untuk menambah voucher baru ke dalam sistem

<Frame>
  ![Image](/images/image-2820.png)
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Nama Voucher | Kolom untuk mengisi nama voucher |
| 2 | Kode Voucher | Kolom untuk mengisi kode voucher |
| 3 | Jangka Waktu | Tombol untuk memilih jangka waktu voucher |
| 4 | Tipe Limit | Tombol untuk memilih tipe limit penggunaan voucher di lingkup organisasi, toko, atau member |
| 5 | Limit Penggunaan | Kolom untuk mengisi kuota penggunaan voucher |
| 6 | Berlaku di Toko | Tombol untuk memilih salah satu atau beberapa toko yang dapat menggunakan voucher |
| 7 | Tipe Voucher | Tombol untuk memilih tipe voucher potongan nominal, persentase, atau produk gratis |
| 8 | Jumlah Potongan | Kolom untuk mengisi nominal atau presentase potongan  transaksi ketika menggunakan voucher |
| 9 | Pilih Produk Gratis | Tombol untuk memilih dan mengisi jumlah produk gratis yang didapat ketika menggunakan voucher |
| 10 | Maksimal Diskon Hingga | Kolom untuk mengisi nominal maksimal potongan yang didapatkan ketika menggunakan voucher |
| 11 | Minimum Transaksi | Kolom untuk mengisi nominal minimum transaksi sebagai syarat penggunaan voucher |
| 12 | Syarat Pembelian Produk Tertentu | Tombol untuk memilih produk tertentu yang harus dibeli pelanggan sebagai syarat penggunaan voucher |
| 13 | Metode Pembayaran | Tombol untuk memilih metode pambayaran tertentu yang dapat menggunakan voucher |
| 14 | Voucher Ekslusif | Tombol untuk mengaktifkan voucher dapat dikombinasikan dengan voucher lainnya |
| 15 | Simpan Voucher | Tombol untuk menyimpan data voucher |

**Berikut cara menambah voucher baru:**

1. Tekan tombol pada halaman list voucher 
   <Frame>
     ![Image](/images/image-300.png)
   </Frame>
2. Masukkan nama voucher di kolom nama voucher
   <Frame>
     ![Input (5)](/images/Input-\(5\).png)
   </Frame>
3. Anda dapat memasukkan kode voucher di kolom kode voucher
   <Frame>
     ![Input (6)](/images/Input-\(6\).png)
   </Frame>
4. Jika kode voucher sudah digunakan maka sistem  akan memberikan peringatan “kode voucher sudah digunakan”
   <Frame>
     ![Input (8)](/images/Input-\(8\).png)
   </Frame>
5. Pilih jangka waktu penggunaan voucher di kolom jangka waktu
   <Frame>
     ![Input (7)](/images/Input-\(7\).png)
   </Frame>
6. Tekan tombol "Tipe Limit" di kolom limit penggunaan untuk memilih tipe cakupan penggunaan voucher per toko atau per member

<Frame>
  ![Input (9)](/images/Input-\(9\).png)
</Frame>

7. Masukkan jumlah kuota penggunaan voucher di kolom jumlah limit

<Frame>
  ![Input (10)](/images/Input-\(10\).png)
</Frame>

8. Tekan tombol "Berlaku di Toko" untuk memilih toko tertentu yang dapat menggunakan voucher

<Frame>
  ![Image](/images/image-2822.png)
</Frame>

9. Pilih salah satu atau beberapa toko sekaligus

<Frame>
  ![Frame 238351](/images/Frame-238351.png)
</Frame>

10. Tekan tombol “Tipe Voucher” di kolom Tipe voucher untuk memilih voucher potongan nominal uang, persentase potongan dari pembelian, atau produk gratis

<Frame>
  ![Image](/images/image-2808.png)
</Frame>

11. **Jika memilih tipe voucher “nominal”** masukkan nominal voucher 

<Frame>
  ![Image](/images/image-2802.png)
</Frame>

12. **Jika memilih tipe voucher “persen”** masukkan persen voucher

<Frame>
  ![Image](/images/image-2803.png)
</Frame>

13. Masukkan nominal maksimal diskon voucher di kolom maks diskon hingga jika voucher memiliki maksimal diskon

<Frame>
  ![Image](/images/image-2804.png)
</Frame>

14. **Jika memilih tipe voucher “produk gratis”** tekan tombol "Pilih Produk yang Didapatkan"

<Frame>
  ![Image](/images/image-2805.png)
</Frame>

15. Pilih salah satu produk gratis untuk voucher tersebut di list produk

<Frame>
  ![Image](/images/image-2806.png)
</Frame>

16. Masukkan jumlah produk gratis yang didapatkan

<Frame>
  ![Image](/images/image-2807.png)
</Frame>

17. Masukkan nominal minimum transaksi di kolom minimum transaksi jika voucher terdapat syarat minimum pembelian

<Frame>
  ![Image](/images/image-2809.png)
</Frame>

18. Jika voucher memiliki syarat pembelian produk tertentu tekan tombol "Produk yang Harus Dibeli"

<Frame>
  ![Image](/images/image-2810.png)
</Frame>

19. Pilih salah satu produk yang harus dibeli sebagai syarat penggunaan voucher di list produk

<Frame>
  ![Image](/images/image-2811.png)
</Frame>

20. Tekan tombol "Metode Pembayaran" untuk memilih metode pembayaran tertentu sebagai syarat menggunakan voucher

<Frame>
  ![Image](/images/image-2812.png)
</Frame>

21. Pilih salah satu atau beberapa metode pembayaran

<Frame>
  ![Image](/images/image-2813.png)
</Frame>

22. Aktifkan atau nonaktifkan voucher dapat digunakan bersamaan dengan voucher lain ketika transaksi

<Frame>
  ![Image](/images/image-2814.png)
</Frame>

23. Setelah selesai mengisi data voucher, kemudian tekan tombol “simpan voucher”

<Frame>
  ![Image](/images/image-310.png)
</Frame>

24. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi simpan voucher

<Frame>
  ![Image](/images/image-2815.png)
</Frame>

25. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk melanjutkan simpan voucher

<Frame>
  ![Image](/images/image-2816.png)
</Frame>

26. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan simpan voucher

<Frame>
  ![Image](/images/image-2817.png)
</Frame>

27. Setelah menekan tombol “Ya, Saya Yakin”,  maka akan menampilkan halaman list voucher serta notifikasi “Voucher Berhasil Disimpan”

## 1.3. Cara Edit Voucher

Edit Voucher adalah fitur yang berfungsi untuk mengubah data voucher yang sudah pernah didaftarkan atau ditambahkan

<Frame>
  ![Desktop 64](/images/Desktop---64.png)
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Nama Voucher | Tombol untuk memilih tanggal pengembalian |
| 2 | Kode Voucher | Tombol untuk mengisi kode voucher |
| 3 | Jangka Waktu | Tombol untuk mengisi jangka waktu voucher |

**Berikut cara mengakses edit voucher:**

1. Tekan tombol aksi (3 titik) pada salah satu voucher di halaman list voucher 

<Frame>
  ![Frame 1016](/images/Frame-1016.png)
</Frame>

2. Setelah menekan tombol, maka akan menampilkan opsi aksi

<Frame>
  ![Frame 237853](/images/Frame-237853.png)
</Frame>

3. Tekan tombol "Ubah Informasi Voucher"

<Frame>
  ![Frame 9 (1)](/images/Frame-9-\(1\).png)
</Frame>

4. Ubah nama voucher di kolom nama voucher

<Frame>
  ![Input](/images/Input-1.png)
</Frame>

5. Anda dapat mengubah kode voucher di kolom kode voucher

<Frame>
  ![Input (1)](/images/Input-\(1\).png)
</Frame>

6. Jika kode voucher sudah digunakan maka sistem akan memberikan peringatan “kode voucher sudah digunakan”

<Frame>
  ![Input (4)](/images/Input-\(4\).png)
</Frame>

7. Ubah jangka waktu voucher

<Frame>
  ![Input (3)](/images/Input-\(3\).png)
</Frame>

8. Setelah selesai mengisi data voucher, kemudian tekan tombol “Simpan Voucher”

<Frame>
  ![Button (1)](/images/Button-\(1\).png)
</Frame>

9. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi simpan voucher

<Frame>
  ![Alter Dialog](/images/alter-dialog.png)
</Frame>

10. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk melanjutkan simpan voucher

<Frame>
  ![Button](/images/Button.png)
</Frame>

11. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan simpan voucher

<Frame>
  ![Image](/images/image-324.png)
</Frame>

12. Setelah menekan tombol “Ya, Saya Yakin”,  maka akan menampilkan halaman list voucher serta notifikasi “Voucher Berhasil Disimpan”
