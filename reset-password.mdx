## **1.1. Cara Melakukan Reset Password Employee**

Menu **Reset Password** adalah menu yang berisi form untuk lupa password di aplikasi Zycas untuk user staff

<Frame>
  ![Image](/images/image-1410.png)
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | No Whatsapp | Kolom untuk mengisi no whatsapp pengguna |
| 2 | Lupa Organisasi | Tombol  untuk mendapatkan informasi ID Organisasi |
| 3 | ID Organisasi | Tombol untuk mengisi ID Organisasi |
| 4 | Kirim Permintaan | Tombol untuk memproses reset password |
| 5 | Kembali ke Login | Tombol untuk kembali ke halaman login |

**Berikut merupakan tahapan reset password:**

1. Pilih tab “Pegawai” di halaman login
   <Frame>
     ![Image](/images/image-1407.png)
   </Frame>
2. Tekan tombol “Lupa Password”
   <Frame>
     ![Image](/images/image-1408.png)
   </Frame>
3. Setelah menekan tombol, maka akan menampilkan halaman lupa password
   <Frame>
     ![Image](/images/image-1409.png)
   </Frame>
4. Masukkan no whatsapp anda di kolom no whatsapp
   <Frame>
     ![Image](/images/image-1411.png)
   </Frame>
5. Masukkan id organisasi anda di kolom id organisasi
   <Frame>
     ![Image](/images/image-1413.png)
   </Frame>
6. Setelah selesai mengisi data reset password, kemudian tekan tombol “Kirim Permintaan”
   <Frame>
     ![Image](/images/image-1412.png)
   </Frame>
7. Setelah menekan tombol, maka akan menampilkan pesan sukses reset password dan diarahkan ke halaman login, informasi password akan dikirim ke no whatsapp user
   <Frame>
     ![Image](/images/image-1414.png)
   </Frame>
