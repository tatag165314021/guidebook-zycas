## **1.2. Cara Tambah Member**

Fitur **Tambah Member** digunakan untuk menambahkan data anggota baru ke dalam sistem. Melalui fitur ini, pengguna dapat menginput informasi member secara lengkap agar tercatat dalam database.

<Frame>
  ![Android Expanded S 751](/images/Android-Expanded--s-751.png "Android Expanded S 751")
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Nama | Tombol untuk mengisi nama pelanggan |
| 2 | Tanggal Lahir | Tombol untuk mengisi tanggal lahir pelanggan |
| 3 | No. KTP | Tombol untuk mengisi no. ktp |
| 4 | No. Telepon | Tombol untuk mengisi no. telepon |
| 5 | Alamat | Tombol untuk mengisi alamat |
| 6 | Add Member | Tombol untuk simpan member |

**Berikut cara menambah member:**

1. Tekan tombol **Tambah Member** di halaman list member

<Frame>
  ![Frame 6 A(3)](/images/Frame-6-a\(3\).png "Frame 6 A(3)")
</Frame>

2. Masukkan nama pelanggan di kolom nama

<Frame>
  <img
    src="/images/image-4.png"
    alt="Image 4"
    title="Image 4"
    className="mx-auto"
    style={{ width:"64%" }}
  />
</Frame>

3. Masukkan tanggal lahir di kolom tanggal lahir

<Frame>
  ![Input Rifght Icon (5)](/images/Input-rifght-icon-\(5\).png "Input Rifght Icon (5)")
</Frame>

4. Masukkan no ktp di kolom no ktp

<Frame>
  <img
    src="/images/No.-KTP.png"
    alt="No KTP"
    title="No KTP"
    className="mx-auto"
  />
</Frame>

5. Masukkan no telepon di kolom no telepon
   <Frame>
     <img
       src="/images/Inpu79t-right-icon-(2).png"
       alt="Inpu79t Right Icon (2)"
       title="Inpu79t Right Icon (2)"
       className="mx-auto"
     />
   </Frame>
6. Jika no telepon ada duplikasi dengan pelanggan lain, maka akan menampilkan halaman konfirmasi ganti no telepon atau nonaktifkan pelanggan
   <Frame>
     ![Frame 1205x (1)](/images/Frame-1205x-\(1\).png "Frame 1205x (1)")
   </Frame>
7. **Ganti no telepon**
8. Tekan tombol “Ganti No Telepon”
   <Frame>
     ![Fram1e 1366](/images/Fram1e-1366.png "Fram1e 1366")
   </Frame>
9. Setelah menekan tombol langkah selanjutnya anda perlu mengganti nomor telepon
10. **Nonaktifkan member**
11. Tekan tombol “Nonaktifkan”
    <Frame>
      ![Fra2me 1365](/images/Fra2me-1365.png "Fra2me 1365")
    </Frame>
12. Setelah menekan tombol maka akan menampilkan sukses menonaktifkan member
13. Masukkan alamat di kolom alamat
    <Frame>
      ![Input Saright Icon (6)](/images/Input-saright-icon-\(6\).png "Input Saright Icon (6)")
    </Frame>
14. Setelah mengisi data pelanggan, kemudian tekan tombol “Simpan Member”
    <Frame>
      ![Frame 1411 A(2)](/images/Frame-1411-a\(2\).png "Frame 1411 A(2)")
    </Frame>
15. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi simpan data member
    <Frame>
      ![Frame 133a6 (7)](/images/Frame-133a6-\(7\).png "Frame 133a6 (7)")
    </Frame>
16. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk menyimpan data member
    <Frame>
      <img
        src="/images/image-21.png"
        alt="Image 21"
        title="Image 21"
        className="mx-auto"
        style={{ width:"62%" }}
      />
    </Frame>
17. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan 
    <Frame>
      <img
        src="/images/image-22.png"
        alt="Image 22"
        title="Image 22"
        style={{ width:"58%" }}
      />
    </Frame>
18. Setelah tekan tombol “Ya, Saya Yakin”, maka akan menampilkan pesan sukses tambah member

## **1.5. Cara Melihat Detail Member**

Fitur Detail Member digunakan untuk melihat informasi rinci tentang member. Melalui fitur ini, pengguna dapat melihat informasi yang tidak dapat dilihat pada tabel list member

<Frame>
  ![Android Expandedq 354](/images/Android-Expandedq---354.png "Android Expandedq 354")
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Close | Tombol untuk menutup halaman |
| 2 | Nama | Informasi nama pelanggan |
| 3 | Tanggal Lahir | Informasi tanggal lahir pelanggan |
| 4 | Terdaftar Sejak | Informasi tanggal awal member registrasi |
| 5 | Status Member | Informasi status member |
| 6 | No. KTP | Informasi no. ktp |
| 7 | No. Telepon | Informasi no. telepon |
| 8 | Alamat | Informasi alamat |
| 9 | Total Pembelian Bulanan | Informasi total pembelian bulanan |
| 10 | Total Pembelian Tahunan | Informasi total pembelian tahunan |
| 11 | Total Pembelian Keseluruhan | Informasi total pembelian keseluruhan |
| 12 | Nominal Hutang Member | Informasi total hutang member |
| 13 | Riwayat Hutang | Tombol untuk melihat riwayat transaksi hutang member |

**Berikut cara mengakses detail member:**

1. Tekan tombol **Detail Member** di halaman list member

<Frame>
  ![Frame 959 (a1)](/images/Frame-959-\(a1\).png "Frame 959 (a1)")
</Frame>

2. Setelah menekan tombol, maka akan menampilkan halaman detail member
3. Tekan Tombol Riwayat Hutang untuk melihat riwayat hutang dari member

<Frame>
  ![Frame 13a85](/images/Frame-13a85.png "Frame 13a85")
</Frame>

4. Tekan tombol close (x), untuk menutup halaman
