**Berikut cara berpindah ke menu kelola toko:**

1. Tekan tombol kelola organisasi di header pojok kanan atas halaman
   <Frame>
     ![Nasevbar](/images/Nasevbar.png "Nasevbar")
   </Frame>
2. Setelah menekan tombol kelola toko, maka akan menampilkan list organisasi
   <Frame>
     ![Home](/images/Home.jpg "Home")
   </Frame>
3. Tekan tombol titik 3 di salah satu list organisasi untuk masuk ke kelola organisasi
   <Frame>
     ![Frame 101s6](/images/Frame-101s6.png "Frame 101s6")
   </Frame>
4. Setelah menekan tombol, maka akan menampilkan list pilihan menu
   <Frame>
     ![Frame 2321s7853](/images/Frame-2321s7853.png "Frame 2321s7853")
   </Frame>
5. Tekan tombol "Kelola Organisasi"
6. Setelah menekan tombol, maka akan menampilkan pop up konfirmasi masuk ke halaman kelola organisasi
   <Frame>
     ![Alter Dialosa1g](/images/alter-dialosa1g.png "Alter Dialosa1g")
   </Frame>
7. Tekan tombol "Tidak" untuk membatalkan masuk ke halaman kelola organisasi
   <Frame>
     ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
   </Frame>
8. Tekan tombol "Ya, Saya Yakin" untuk masuk ke halaman kelola organisasi
   <Frame>
     ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
   </Frame>
9. Setelah menekan tombol "Ya, Saya Yakin", maka akan diarahkan ke halaman dashboard organisasi
