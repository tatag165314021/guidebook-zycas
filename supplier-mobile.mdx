## **1.2. Cara Tambah Supplier**

Tambah Supplier merupakan fitur yang berfungsi untuk menambah data supplier baru ke dalam sistem. Supplier nantinya akan digunakan pada saat menambah stok produk.

<Frame>
  ![Android Expandted 750](/images/Android-Expandted---750.png "Android Expandted 750")
</Frame>

| No. | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Nama Toko | Kolom untuk menginputkan nama toko |
| 2 | PIC Toko | Kolom untuk menginputkan PIC toko |
| 3 | No. Telp | Kolom untuk menginputkan no. tlp toko |
| 4 | Simpan Supplier | Tombol untuk menyimpan supplier |

**Berikut adalah langkah-langkah untuk menambah supplier:**

1. Tekan pada tombol Tambah Supplier di sebelah kanan atas

<Frame>
  ![Fra7jgme 6](/images/Fra7jgme-6.png "Fra7jgme 6")
</Frame>

2. Lalu mulai bisa input Nama Toko yang ingin ditambahkan (maksimal 120 karakter)

<Frame>
  ![Inputgt Right Icon](/images/Inputgt-right-icon.png "Inputgt Right Icon")
</Frame>

3. Setelah itu bisa input PIC Toko (maksimal 120 karakter)

<Frame>
  ![Input Rightik Icon (1)](/images/Input-rightik-icon-\(1\).png "Input Rightik Icon (1)")
</Frame>

4. Lalu Input No. Tlp Toko (maksimal 16 karakter)

<Frame>
  ![Inpu79t Right Icon (2)](/images/Inpu79t-right-icon-\(2\).png "Inpu79t Right Icon (2)")
</Frame>

5. Setelah data supplier dirasa sudah benar lanjut tekan Simpan Supplier

<Frame>
  ![Frame 148811 (1)](/images/Frame-148811-\(1\).png "Frame 148811 (1)")
</Frame>

6. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi simpan data supplier yang baru saja ditambahkan

<Frame>
  ![Fra7yme 1336 (3)](/images/Fra7yme-1336-\(3\).png "Fra7yme 1336 (3)")
</Frame>

7. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk menyimpan data supplier
   <Frame>
     <img
       src="/images/image-21.png"
       alt="Image 21"
       title="Image 21"
       style={{ width:"60%" }}
     />
   </Frame>
8. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan 

<Frame>
  <img
    src="/images/image-22.png"
    alt="Image 22"
    title="Image 22"
    style={{ width:"54%" }}
  />
</Frame>

9. Setelah konfirmasi berlangsung akan lanjut ke halaman list supplier yang sudah tersimpan serta dengan tanda alert berhasil.

## 1.3. Cara Edit Supplier

Edit Supplier merupakan fitur yang berfungsi untuk mengubah atau mengedit data supplier yang sudah pernah di daftarkan di sistem. 

<Frame>
  ![Android Expandted 750](/images/Android-Expandted---750.png "Android Expandted 750")
</Frame>

| No. | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Nama Toko | Kolom untuk mengedit nama toko |
| 2 | PIC Toko | Kolom untuk mengedit PIC toko |
| 3 | No. Tlp | Kolom untuk mengedit no. tlp toko |
| 4 | Simpan Supplier | Tombol untuk menyimpan perubahan data supplier |

**Berikut cara mengedit supplier:**

1. Tekan pada icon Edit yang ada di kolom Aksi pada salah satu list supplier
   <Frame>
     ![Frankme 21](/images/Frankme-21.png "Frankme 21")
   </Frame>
2. Setelah itu input di kolom Nama Toko untuk mengedit Nama Toko (maksimal 120 karakter)

<Frame>
  ![Inputgt Right Icon](/images/Inputgt-right-icon.png "Inputgt Right Icon")
</Frame>

3. Lalu, input di kolom PIC Toko untuk mengedit PIC Toko (maksimal 120 karakter)

<Frame>
  ![Input Rightik Icon (1)](/images/Input-rightik-icon-\(1\).png "Input Rightik Icon (1)")
</Frame>

4. Input di kolom No. Telp untuk mengedit No. Telp Toko (maksimal 16 karakter)

<Frame>
  ![Inpu79t Right Icon (2)](/images/Inpu79t-right-icon-\(2\).png "Inpu79t Right Icon (2)")

| Pengguna (User) | Orang yang menggunakan aplikasi Zycas Mobile dengan hak akses tertentu. |
| Owner | Pengguna dengan hak akses penuh yang dapat mengelola seluruh menu dan fitur dalam aplikasi Zycas. |
| Karyawan | Pengguna dengan hak akses terbatas sesuai izin yang diberikan oleh owner. |
| Hak Akses | Izin yang menentukan menu dan fitur apa saja yang dapat diakses oleh pengguna. |
| Supplier | Pemasok atau pihak yang menyediakan produk kepada toko atau bisnis. |
| Modul Supplier | Modul manajemen data pemasok yang digunakan untuk mengelola informasi vendor atau distributor produk. |
| List Supplier | Halaman yang menampilkan daftar seluruh supplier yang terdaftar dalam sistem. |
| Tambah Supplier | Fitur atau tombol untuk menambahkan data supplier baru ke dalam sistem. |
| Edit Supplier | Fitur untuk mengubah atau memperbarui data supplier yang sudah terdaftar. |
| Nama Toko | Nama toko atau perusahaan milik supplier yang menjadi pemasok produk. |
| PIC Toko | Orang yang menjadi penanggung jawab atau kontak utama dari pihak supplier. |
| No. Telp | Nomor telepon supplier yang digunakan sebagai informasi kontak. |
| Cari Supplier | Fitur pencarian untuk menemukan supplier berdasarkan kata kunci tertentu. |
| Aksi Detail | Ikon atau tombol untuk melihat informasi detail dari data supplier. |
| Sidebar Menu | Panel navigasi yang muncul setelah menekan ikon hamburger. |

| Menu Stok | Menu dalam aplikasi Zycas yang berisi fitur pengelolaan data stok dan supplier. |
| Simpan Supplier | Tombol untuk menyimpan data supplier baru atau perubahan data supplier. |
| Konfirmasi Simpan Supplier | Halaman konfirmasi yang muncul sebelum data supplier disimpan ke sistem. |
| Notifikasi Berhasil | Pesan sistem yang menandakan proses penyimpanan atau pembaruan data supplier berhasil. |
| Tracking Pembelian | Proses pemantauan riwayat dan aktivitas pembelian produk dari setiap supplier. |
