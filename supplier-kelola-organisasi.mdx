## **1.1. Cara Mengakses List Supplier**

**Berikut cara mengakses menu Supplier:** 

1. Lalu tekan menu Supplier pada list menu di sidebar kelola organisasi
   <Frame>
     ![ONLY ORGANISASI (63rwcdsd)](/images/ONLY-ORGANISASI-\(63rwcdsd\).png "ONLY ORGANISASI (63rwcdsd)")
   </Frame>
2. Setelah menekan menu Supplier maka akan menampilkan halaman List Supplier

## **1.2. Cara Tambah Supplier**

Tambah Supplier merupakan fitur yang berfungsi untuk menambah data supplier baru ke dalam sistem. Supplier nantinya akan digunakan pada saat menambah stok produk.

<Frame>
  ![Alter Dialog (6wer34d)](/images/alter-dialog-\(6wer34d\).png "Alter Dialog (6wer34d)")
</Frame>

<table>
  <colgroup>

  <thead>
    <tr>
      <th>No.</th>
      <th>Simbol</th>
      <th>Keterangan</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>1</td>
      <td>Nama Supplier</td>
      <td>Kolom untuk menginputkan nama supplier</td>
    </tr>
    <tr>
      <td>2</td>
      <td>PIC Supplier</td>
      <td>Kolom untuk menginputkan PIC supplier</td>
    </tr>
    <tr>
      <td>3</td>

      <td>Kolom untuk menginputkan no. tlp supplier</td>

      <td>Tombol untuk menyimpan supplier</td>
    </tr>

**Berikut adalah langkah-langkah untuk menambah supplier:** 

1. Tekan pada tombol Tambah Supplier di sebelah kanan atas
   <Frame>
     ![Button (1sdwee0)](/images/Button-\(1sdwee0\).png "Button (1sdwee0)")
   </Frame>
2. Setelah menekan tombol, maka akan menampilkan halaman form input supplier
3. Lalu mulai bisa input Nama Supplier yang ingin ditambahkan (maksimal 120 karakter)
   <Frame>
     ![Input Sdfr(6)](/images/Input-sdfr\(6\).png "Input Sdfr(6)")
   </Frame>
4. Setelah itu bisa input PIC Supplier (maksimal 120 karakter)
   <Frame>
     ![Input (7sdfertt5g)](/images/Input-\(7sdfertt5g\).png "Input (7sdfertt5g)")
   </Frame>
5. Lalu Input No. Telp
   <Frame>
     ![Input (2qa5)](/images/Input-\(2qa5\).png "Input (2qa5)")
   </Frame>
6. Setelah data supplier dirasa sudah benar lanjut tekan Simpan Supplier
   <Frame>
     ![Button (11hfwuerwf)](/images/Button-\(11hfwuerwf\).png "Button (11hfwuerwf)")
   </Frame>
7. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi simpan data supplier yang baru saja ditambahkan
   <Frame>
     ![Alter Dialog (7fefrtt)](/images/alter-dialog-\(7fefrtt\).png "Alter Dialog (7fefrtt)")
   </Frame>
8. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk menyimpan data supplier
   <Frame>
     ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
   </Frame>
9. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan 
   <Frame>
     ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
   </Frame>
10. Setelah menekan tombol "Ya, Saya Yakin" maka akan memproses simpan data supplier dan diarahkan ke halaman list supplier
