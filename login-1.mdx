**Berikut merupakan tahapan login akun:**

1. Akses link Zycas Desktop, maka akan diarahkan ke halaman login
2. Pilih tab “Owner”
   <Frame>
     ![Bottoswm](/images/bottoswm.png "Bottoswm")
   </Frame>
3. Masukkan no whatsapp anda di kolom no whatsapp
   <Frame>
     ![WA](/images/WA.png "WA")
   </Frame>
4. Masukkan password anda di kolom password
   <Frame>
     ![Password](/images/Password.png "Password")
   </Frame>
5. Setelah selesai mengisi data login, kemudian tekan tombol “Login”
   <Frame>
     ![Button](/images/Button.png "Button")
   </Frame>
6. Setelah menekan tombol, jika data valid maka akan menampilkan halaman home
   <Frame>
     ![Home](/images/Home.jpg "Home")
   </Frame>
7. Tekan tombol aksi dengan ikon 3 titik pada salah satu organisasi di list organisasi untuk menampilkan opsi menu
   <Frame>
     ![Frame 101s6](/images/Frame-101s6.png "Frame 101s6")
   </Frame>
8. **Jika user memilih masuk kelola organisasi (ikuti langkah 9 - 13)**
9. Tekan tombol "Kelola Organisasi"
   <Frame>
     ![Frame 2321s7853](/images/Frame-2321s7853.png "Frame 2321s7853")
   </Frame>
10. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi pilih organisasi
    <Frame>
      ![Alter Dialosa1g](/images/alter-dialosa1g.png "Alter Dialosa1g")
    </Frame>
11. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk masuk dashboard organisasi
    <Frame>
      ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
    </Frame>
12. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan 
    <Frame>
      ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
    </Frame>
13. Setelah tekan tombol “Ya, Saya Yakin”, maka akan diarahkan ke dashboard organisasi
14. **Jika user memilih masuk kelola toko (ikuti langkah 15 - 22)**
15. Tekan tombol "Kelola Toko"
    <Frame>
      ![Frame 2321s7853](/images/Frame-2321s7853.png "Frame 2321s7853")
    </Frame>
16. **Jika user hanya memiliki satu toko, maka akan diarahkan ke halaman dashboard toko tersebut**
17. **Jika user memiliki lebih dari satu toko, maka akan diarahkan ke halaman list toko**
    <Frame>
      ![Linkesw2d Device](/images/Linkesw2d-Device.jpg "Linkesw2d Device")
    </Frame>
18. Tekan tombol "Masuk Dashboard" di salah satu toko
    <Frame>
      ![Butto24en (3)](/images/Butto24en-\(3\).png "Butto24en (3)")
    </Frame>
19. Setelah menekan tombol maka akan menampilkan halaman konfirmasi pilih toko
    <Frame>
      ![Alter Dialos2g (1)](/images/alter-dialos2g-\(1\).png "Alter Dialos2g (1)")
    </Frame>
20. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk masuk ke dashboard toko
    <Frame>
      ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
    </Frame>
21. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan masuk ke dashboard toko
    <Frame>
      ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
    </Frame>
22. Setelah tekan tombol “Ya, Saya Yakin”, maka akan diarahkan ke dashboard toko
