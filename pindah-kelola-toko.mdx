**Berikut cara berpindah ke menu kelola toko:**

1. Tekan tombol kelola toko  di header pojok kanan atas halaman
   <Frame>
     ![Navbar (dftr1)](/images/Navbar-\(dftr1\).png "Navbar (dftr1)")
   </Frame>
2. Setelah menekan tombol kelola toko, maka akan menampilkan list toko
   <Frame>
     ![Linkesw2d Device](/images/Linkesw2d-Device.jpg "Linkesw2d Device")
   </Frame>
3. Tekan tombol "Masuk Dashboard" di salah satu list toko untuk masuk ke kelola toko
   <Frame>
     ![Butto24en (3)](/images/Butto24en-\(3\).png "Butto24en (3)")
   </Frame>
4. Setelah menekan tombol, maka akan menampilkan pop up konfirmasi masuk ke halaman kelola toko
   <Frame>
     ![Alter Dialos2g (1)](/images/alter-dialos2g-\(1\).png "Alter Dialos2g (1)")
   </Frame>
5. Tekan tombol "Tidak" untuk membatalkan masuk ke halaman kelola toko
   <Frame>
     ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
   </Frame>
6. Tekan tombol "Ya Saya Yakin" untuk masuk ke halaman kelola toko
   <Frame>
     ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
   </Frame>
7. Setelah menekan tombol "Ya, Saya Yakin", maka akan diarahkan ke halaman dashboard kelola toko
