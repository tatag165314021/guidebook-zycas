Penjualan Produk Varian menampilkan performa penjualan untuk setiap varian produk, seperti ukuran, warna, atau tipe tertentu. Pengguna dapat melihat jumlah terjual dan pendapatan per varian sehingga memudahkan analisis popularitas varian dan membantu dalam pengelolaan stok serta strategi penjualan yang lebih tepat.

## **1.1. Cara Akses Penjualan Produk Varian**

**Berikut cara mengakses menu penjualan produk varian:**

1. Tekan menu Penjualan > Penjualan Varian pada list menu pada sidebar kelola toko

<Frame>
  ![ONLY TOKO (4ewerw3f)](/images/ONLY-TOKO-\(4ewerw3f\).png "ONLY TOKO (4ewerw3f)")
</Frame>

2. Setelah menekan menu Penjualan Produk Varian maka akan menampilkan halaman Penjualan Produk Varian
3. Tekan tombol “Periode” untuk filter data laporan penjualan produk varian

<Frame>
  ![Input (2sdfsdfs6)](/images/Input-\(2sdfsdfs6\).png "Input (2sdfsdfs6)")
</Frame>

4. **Jika memilih filter mingguan klik tab “Mingguan”**

<Frame>
  ![Popover (aasdwaaww)](/images/popover-\(aasdwaaww\).png "Popover (aasdwaaww)")
</Frame>

5. Pilih minggu dengan range tertentu
6. Setelah memilih minggu, tekan tombol “Terapkan Periode”
7. Setelah menekan tombol maka akan menampilkan data sesuai minggu di filter
8. **Jika memilih filter bulanan klik tab “Bulanan”**

<Frame>
  ![Popover (8sdsdfwwaw)](/images/popover-\(8sdsdfwwaw\).png "Popover (8sdsdfwwaw)")
</Frame>

9. Pilih bulan dengan range tertentu
10. Setelah memilih bulan, tekan tombol “Terapkan Periode”
11. Setelah menekan tombol maka akan menampilkan data sesuai bulan di filter
12. **Jika memilih filter kuartal klik tab “Kuartal”**

<Frame>
  ![Popover (9sdfesdes)](/images/popover-\(9sdfesdes\).png "Popover (9sdfesdes)")
</Frame>

13. Pilih kuartal dengan range tertentu
14. Setelah memilih kuartal, tekan tombol “Terapkan Periode”
15. Setelah menekan tombol maka akan menampilkan data sesuai kuartal di filter
16. Tekan tombol “Nama Produk” untuk filter data laporan penjualan produk varian dari produk tertentu

<Frame>
  ![Input (2erwedses5)](/images/Input-\(2erwedses5\).png "Input (2erwedses5)")
</Frame>

17. Tekan tombol “Nama Varian” untuk filter data laporan penjualan produk varian dari varian tertentu

<Frame>
  ![Input (27sdfsdfa)](/images/Input-\(27sdfsdfa\).png "Input (27sdfsdfa)")
</Frame>
