Pada halaman awal setelah membuka aplikasi, jika anda belum login & device belum terkunci, Anda akan dihadapkan dengan form login untuk dapat menggunakan aplikasi Zycas.

<Frame>
  ![Login Page](/images/login-page.png "Login Page")
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | No Whatsapp | Kolom untuk mengisi no whatsapp pengguna ketika login |
| 2 | Password | Kolom untuk mengisi password pengguna ketika login |
| 3 | Masuk | Tombol untuk login aplikasi |
| 4 | Daftarkan Akun | Tombol untuk melakukan registrasi akun |
| 5 | Reset Password | Tombol untuk lupa password |

## **1.1. Cara Melakukan Login Pertama Kali**

Anda dapat melakukan login pertama kali atau kondisi device anda belum terkunci untuk organisasi atau toko milik anda.

**Berikut merupakan tahapan login akun:**

1. Buka aplikasi Zycas dalam kondisi belum login, maka akan diarahkan ke halaman login
2. Masukkan no whatsapp anda dengan benar di kolom no whatsapp
   <Frame>
     ![Input Whatsapp Login](/images/Input-whatsapp-login.png "Input Whatsapp Login")
   </Frame>
   Masukkan password anda dengan benar di kolom password
   <Frame>
     ![Input Password Login](/images/input-password-login.png "Input Password Login")
   </Frame>
3. Setelah selesai mengisi data login, kemudian tekan tombol “Masuk”
   <Frame>
     ![Tombol Masuk](/images/tombol-masuk.png "Tombol Masuk")
   </Frame>
4. Setelah menekan tombol, maka akan menampilkan halaman pilih organisasi
   <Frame>
     ![Pilih Organisasi Login](/images/pilih-organisasi-login.png "Pilih Organisasi Login")
   </Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Buat Organisasi | Tombol untuk membuat organisasi baru |
| 2 | Cari Organisasi | Kolom untuk pencarian list organisasi |
| 3 | List Organisasi | Tombol untuk memilih organisasi saat login |
| 4 | Simpan dan Pilih Toko | Tombol untuk melanjutkan proses memilih toko dari organisasi yang sudah dipilih |

6. Pilih salah satu organisasi yang anda miliki

<Frame>
  ![Pilih Salah Satu Org](/images/pilih-salah-satu-org.png "Pilih Salah Satu Org")
</Frame>

7. Setelah selesai memilih organisasi, kemudian tekan tombol “Simpan dan Pilih Toko”

<Frame>
  ![Tombol Simpan Dan Pilih Toko](/images/tombol-simpan-dan-pilih-toko.png "Tombol Simpan Dan Pilih Toko")
</Frame>

8. Setelah menekan tombol, maka akan menampilkan halaman pilih toko dari list toko sesuai organisasi yang anda pilih

<Frame>
  ![Pilih Toko Login](/images/pilih-toko-login.png "Pilih Toko Login")
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Buat Toko | Tombol untuk membuat toko baru di organisasi |
| 2 | Cari Toko | Kolom untuk pencarian list toko |
| 3 | List Toko | Tombol untuk memilih toko saat login |
| 4 | Simpan dan Kunci Device | Tombol untuk melanjutkan proses kunci device |

9. Pilih salah satu toko yang anda miliki

<Frame>
  ![Pilih Salah Satu Toko](/images/pilih-salah-satu-toko.png "Pilih Salah Satu Toko")
</Frame>

10. Setelah selesai memilih toko, kemudian tekan tombol “Simpan dan Kunci Device”

<Frame>
  ![Tombol Simpan Dan Kunci Dev](/images/tombol-simpan-dan-kunci-dev.png "Tombol Simpan Dan Kunci Dev")
</Frame>

11. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi kunci device

<Frame>
  ![Halaman Kunci Device](/images/halaman-kunci-device-1.png "Halaman Kunci Device")
</Frame>

12. Masukkan no device di kolom no device

<Frame>
  ![Input No Device Login](/images/input-no-device-login.png "Input No Device Login")
</Frame>

13. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk melanjutkan proses login

<Frame>
  ![Tombol Ya Saya Yakin Login](/images/tombol-ya-saya-yakin-login.png "Tombol Ya Saya Yakin Login")
</Frame>

14. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan login

<Frame>
  ![Tombol Tidak Login](/images/tombol-tidak-login.png "Tombol Tidak Login")
</Frame>

15. Setelah menekan tombol “Ya, Saya Yakin”, maka akan menampilkan halaman pengisian OTP

<Frame>
  ![Otp Login](/images/otp-login.png "Otp Login")
</Frame>

16. Masukkan kode otp sesuai dengan kode yang dikirimkan di no whatsapp anda

<Frame>
  ![Input Otp Login](/images/input-otp-login.png "Input Otp Login")
</Frame>

17. Setelah mengisi kode otp, jika kode otp benar, maka akan menampilkan pesan sukses dan diarahkan ke halaman detail device terkunci di organisasi dan toko

<Frame>
  ![Device Lock Login](/images/device-lock-login.png "Device Lock Login")
</Frame>

18. Tekan tombol “Menuju Dashboard” di halaman detail device untuk diarahkan ke halaman dashboard Zycas

![Tombol Menuju Dashboard](/images/tombol-menuju-dashboard.png "Tombol Menuju Dashboard")
