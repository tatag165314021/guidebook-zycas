**Berikut merupakan tahapan membuat toko:**

1. Tekan tombol “Tambah Toko” di halaman list Toko untuk memulai proses penambahan data toko baru
   <Frame>
     ![Butt57on (13)](/images/Butt57on-\(13\).png "Butt57on (13)")
   </Frame>
2. Setelah menekan tombol maka akan menampilkan halaman form input toko
3. Masukkan nama toko di kolom nama toko
   <Frame>
     ![Input (7wrs)](/images/Input-\(7wrs\).png "Input (7wrs)")
   </Frame>
4. Tekan tombol “Tipe Toko” untuk memilih tipe toko
5. Tekan tombol “Jenis Toko” untuk memilih jenis toko
   <Frame>
     ![Input (uj9)](/images/Input-\(uj9\).png "Input (uj9)")
   </Frame>
6. Masukkan alamat toko di kolom alamat
   <Frame>
     ![Input (26)6r4](/images/Input-\(26\)6r4.png "Input (26)6r4")
   </Frame>
7. Masukkan no whatsapp toko di kolom no whatsapp
   <Frame>
     ![Input76g6](/images/Input76g6.png "Input76g6")
   </Frame>
8. Tekan tombol “Pilih Lokasi” untuk memilih lokasi toko
9. Setelah menekan tombol, maka akan menampilkan halaman input lokasi
10. Pasang pin lokasi sesuai koordinat toko
11. Setelah selesai memasang pin lokasi, kemudian tekan tombol “Pilih Lokasi”
12. Setelah menekan tombol, maka akan menampilkan koordinat lokasi di halaman buat toko
13. Setelah selesai mengisi data toko, kemudian tekan tombol “Simpan Toko”
    <Frame>
      ![Frame 237856swa](/images/Frame-237856swa.png "Frame 237856swa")
    </Frame>
14. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi simpan toko
    <Frame>
      ![Alter Dialo1g (7)](/images/alter-dialo1g-\(7\).png "Alter Dialo1g (7)")
    </Frame>
15. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk simpan toko
    <Frame>
      ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
    </Frame>
16. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan simpan toko
    <Frame>
      ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
    </Frame>
17. Setelah menekan tombol “Ya, Saya Yakin”, maka akan menampilkan pesan sukses membuat toko dan diarahkan ke halaman list toko

## **1.3. Cara Edit Toko**

Pada tampilan **Halaman List Organisasi**, klik tombol **Edit Organisasi**. Fitur ini berguna apabila terjadi kesalahan input data saat pertama kali ditambahkan, atau jika terdapat perubahan informasi organisasi.

<Frame>
  ![Edit Tokoeedw](/images/Edit-Tokoeedw.jpg "Edit Tokoeedw")
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Nama Toko | Kolom untuk mengisi nama toko |
| 2 | No Whatsapp | Kolom untuk mengisi no whatsapp |
| 3 | Tipe Toko | Dropdown untuk memilih tipe toko |
| 4 | Lokasi | Tombol untuk mengisi lokasi toko |
| 5 | Jenis Toko | Dropdown untuk memilih jenis toko |
| 6 | Alamat | Kolom untuk mengisi alamat |
| 7 | Simpan Toko | Tombol untuk memproses simpan toko |
| 8 | Reset Data Toko | Tombol untuk mengembalikan data toko kembali ke sebelum diubah |
| 9 | Kembali ke List Toko | Tombol untuk kembali ke list toko |
