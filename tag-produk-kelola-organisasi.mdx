## **1.1. Cara Akses Master Data Tag Produk**

**Berikut cara mengakses menu master data tag produk:**

1. Tekan menu Tags pada list menu di sidebar kelola organisasi
   <Frame>
     ![ONLY ORGANISASI (4fwerwfsd)](/images/ONLY-ORGANISASI-\(4fwerwfsd\).png "ONLY ORGANISASI (4fwerwfsd)")
   </Frame>
2. Sistem akan menampilkan halaman **List Master Data Tag Produk**

## **1.2. Cara Menambah Tag Produk**

**Berikut cara menambah tags Produk**

1. Tekan tombol “Tambah Tags” di halaman list tags produk
   <Frame>
     ![Button (6cdfsfe)](/images/Button-\(6cdfsfe\).png "Button (6cdfsfe)")
   </Frame>
2. Setelah menekan tombol, maka akan menampilkan halaman input tag
3. Masukkan nama tag  di kolom nama tag
   <Frame>
     ![Input (4swe32edw)](/images/Input-\(4swe32edw\).png "Input (4swe32edw)")
   </Frame>
4. Setelah selesai mengisi tags, kemudian tekan tombol “Simpan Tag”
   <Frame>
     ![Frame 141q2](/images/Frame-141q2.png "Frame 141q2")
   </Frame>
5. Setelah selesai menekan tombol, maka akan menampilkan halaman konfirmasi simpan tag produk
   <Frame>
     ![Alter Dialog (gyu8g4)](/images/alter-dialog-\(gyu8g4\).png "Alter Dialog (gyu8g4)")
   </Frame>
6. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk menyimpan data  tag produk
   <Frame>
     ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
   </Frame>
7. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan 
   <Frame>
     ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
   </Frame>
8. Setelah tekan tombol “Ya, Saya Yakin”, maka akan menampilkan pesan sukses simpan tag

## **1.3. Cara Mengubah Tag Produk**

**Berikut cara mengubah tags Produk**

1. Tekan tombol edit tag di halaman list tags produk
   <Frame>
     ![Button (2h473)](/images/Button-\(2h473\).png "Button (2h473)")
   </Frame>
2. Setelah menekan tombol, maka akan menampilkan halaman input tag
3. Ubah nama tags  di kolom nama tag
   <Frame>
     ![Input (4swe32edw)](/images/Input-\(4swe32edw\).png "Input (4swe32edw)")
   </Frame>
4. Setelah selesai mengubah tags, kemudian tekan tombol “Simpan Tag”
   <Frame>
     ![Frame 141q2](/images/Frame-141q2.png "Frame 141q2")
   </Frame>
5. Setelah selesai menekan tombol, maka akan menampilkan halaman konfirmasi simpan tags produk
   <Frame>
     ![Alter Dialog (gyu8g4)](/images/alter-dialog-\(gyu8g4\).png "Alter Dialog (gyu8g4)")
   </Frame>
6. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk menyimpan data  tags produk
   <Frame>
     ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
   </Frame>
7. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan
   <Frame>
     ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
   </Frame>
8. Setelah tekan tombol “Ya, Saya Yakin”, maka akan menampilkan pesan sukses simpan tag
