title: "Transaksi Void Organisasi"

Laporan Void menampilkan daftar transaksi yang dibatalkan (void), lengkap dengan informasi waktu pembatalan, kasir yang melakukan void, dan alasan pembatalan. Fitur ini membantu pengguna memantau aktivitas pembatalan transaksi untuk kebutuhan audit, pengawasan, dan memastikan tidak ada penyalahgunaan proses void.

## **1.1. Cara Akses Laporan Void**

**Berikut cara mengakses menu laporan void:**

1. Tekan menu Operasional > Transaksi Void pada list menu di sidebar kelola organisasi
   <Frame>
     ![ONLY ORGANISASI (15)fgdfgdfgr](/images/ONLY-ORGANISASI-\(15\)fgdfgdfgr.png "ONLY ORGANISASI (15)fgdfgdfgr")
   </Frame>
2. Setelah menekan menu Laporan Void maka akan menampilkan halaman Laporan Void
3. Tekan tombol “Periode” untuk filter data laporan void
   <Frame>
     ![Input (17dsdssa)](/images/Input-\(17dsdssa\).png "Input (17dsdssa)")
   </Frame>
4. **Jika memilih filter harian klik tab “Harian”**
   <Frame>
     ![Popoverdasdasda](/images/popoverdasdasda.png "Popoverdasdasda")
   </Frame>
5. Pilih tanggal dengan range tertentu
6. Setelah memilih tanggal, tekan tombol “Terapkan Periode”
7. Setelah menekan tombol maka akan menampilkan data sesuai tanggal di filter
8. **Jika memilih filter bulanan klik tab “Bulanan”**
   <Frame>
     ![Popover (1dsfsdfsdf)](/images/popover-\(1dsfsdfsdf\).png "Popover (1dsfsdfsdf)")
   </Frame>
9. Pilih bulan dengan range tertentu
10. Setelah memilih bulan, tekan tombol “Terapkan Periode”
11. Setelah menekan tombol maka akan menampilkan data sesuai bulan di filter
12. **Jika memilih filter kuartal klik tab “Kuartal”**
    <Frame>
      ![Popover (2sdfsdfeas)](/images/popover-\(2sdfsdfeas\).png "Popover (2sdfsdfeas)")
    </Frame>
13. Pilih kuartal dengan range tertentu
14. Setelah memilih kuartal, tekan tombol “Terapkan Periode”
15. Setelah menekan tombol maka akan menampilkan data sesuai kuartal di filter
16. **Jika memilih filter tahun klik tab “Tahunan”**
    <Frame>
      ![Popover (3sdfsdfea)](/images/popover-\(3sdfsdfea\).png "Popover (3sdfsdfea)")
    </Frame>
17. Pilih tahun dengan range tertentu
18. Setelah memilih tahun, tekan tombol “Terapkan Periode”
19. Setelah menekan tombol maka akan menampilkan data sesuai tahun di filter
20. Masukkan kata kunci tertentu di kolom cari no nota untuk mencari data laporan void dengan cepat
    <Frame>
      ![Input (24efsesd)](/images/Input-\(24efsesd\).png "Input (24efsesd)")
    </Frame>
21. Tekan tombol “Penanggungjawab Void” untuk filter data laporan void dari penanggungjawab (yang melakukan pembatalan transaksi) tertentu
    <Frame>
      ![Input (23dasdaxa)](/images/Input-\(23dasdaxa\).png "Input (23dasdaxa)")
    </Frame>
22. Tekan tombol “Nama Kasir” untuk filter data laporan void dari kasir tertentu
    <Frame>
      ![Input (22sfsdfewds)](/images/Input-\(22sfsdfewds\).png "Input (22sfsdfewds)")
    </Frame>
23. Tekan tombol “Nama Toko” untuk filter data laporan void dari toko tertentu
    <Frame>
      ![Inputfiltertoko](/images/Inputfiltertoko.png "Inputfiltertoko")
    </Frame>
