## **1.1. Cara Akses Master Data Jabatan**

**Berikut cara mengakses menu master data jabatan:**

1. Tekan ikon tiga garis di pojok kiri atas

<Frame>
  ![Frame 1332](/images/Frame-1332.png "Frame 1332")
</Frame>

2. Setelah menekan ikon hamburger, maka akan menampilkan sidebar list menu

<Frame>
  <img
    src="/images/800-PsX-(2).png"
    alt="800 Ps X (2)"
    title="800 Ps X (2)"
    style={{ width:"53%" }}
  />
</Frame>

3. Tekan menu Master Data pada list menu

<Frame>
  ![Frame 1a186](/images/Frame-1a186.png "Frame 1a186")
</Frame>

4. Setelah tekan menu Master Data, maka akan menampilkan list sub menu Master Data

<Frame>
  ![Frame 139q1](/images/Frame-139q1.png "Frame 139q1")

<Frame>
  ![Fra45me 1181](/images/Fra45me-1181.png "Fra45me 1181")
</Frame>

6. Sistem akan menampilkan halaman **List Master Data Jabatan**

## **1.2. Cara Menambah Jabatan**

**Berikut cara menambah jabatan:**

1. Tekan tombol “Tambah jabatan” di halaman list jabatan 

<Frame>
  ![Framwsae 960 (1)](/images/Framwsae-960-\(1\).png "Framwsae 960 (1)")
</Frame>

2. Setelah menekan tombol, maka akan menampilkan halaman input jabatan

<Frame>
  ![Android Expand452ed 128](/images/Android-Expand452ed---128.png "Android Expand452ed 128")
</Frame>

3. Masukkan nama jabatan  di kolom nama jabatan

<Frame>
  ![Input Right Q6icon (3)](/images/Input-right-q6icon-\(3\).png "Input Right Q6icon (3)")
</Frame>

4. Tekan tombol permission untuk mengaktifkan hak akses jabatan

<Frame>
  ![Fra3ewme 588](/images/Fra3ewme-588.png "Fra3ewme 588")
</Frame>

5. Setelah selesai mengisi jabatan, kemudian tekan tombol “Simpan jabatan ”

<Frame>
  ![Frame W1369](/images/Frame-w1369.png "Frame W1369")
</Frame>

6. Setelah selesai menekan tombol, maka akan menampilkan halaman konfirmasi simpan jabatan 

<Frame>
  ![Frame 133y6 (4)](/images/Frame-133y6-\(4\).png "Frame 133y6 (4)")
</Frame>

7. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk menyimpan data jabatan 

<Frame>
  <img
    src="/images/image-21.png"
    alt="Image 21"
    title="Image 21"
    style={{ width:"72%" }}
  />
</Frame>

8. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan 

<Frame>
  <img
    src="/images/image-22.png"

    title="Image 22"
    style={{ width:"59%" }}
  />
</Frame>

9. Setelah tekan tombol “Ya, Saya Yakin”, maka akan menampilkan pesan sukses simpan jabatan

## **Glosarium**

| **Istilah** | **Deskripsi (Penjelasan dalam Bahasa Indonesia)** |
| :-- | :-- |
| Zycas Mobile | Aplikasi mobile untuk pengelolaan operasional bisnis ritel yang mencakup transaksi, stok, dan konfigurasi sistem. |
| Pengguna (User) | Individu yang menggunakan aplikasi Zycas dengan hak akses tertentu. |
| Owner | Pengguna dengan hak akses penuh untuk mengelola seluruh menu dan konfigurasi sistem. |
| Karyawan | Pengguna dengan hak akses terbatas sesuai pengaturan dari owner. |
| Hak Akses | Izin yang menentukan menu dan fitur yang dapat digunakan oleh pengguna. |
| Master Data | Modul pusat konfigurasi sistem untuk mengelola pengaturan dasar yang digunakan oleh seluruh modul Zycas. |
| Foundational Settings | Pengaturan dasar sistem yang menjadi fondasi bagi modul operasional lainnya. |
| Backbone Sistem | Struktur utama sistem yang menopang seluruh konfigurasi dan proses aplikasi. |
| POS (Point of Sale) | Modul kasir yang menggunakan data dari Master Data untuk proses transaksi. |
| Edit Pajak | Fitur untuk mengubah persentase pajak yang digunakan dalam transaksi. |
| Persen Pajak | Nilai persentase pajak yang dikenakan pada transaksi penjualan. |
| NPWP | Nomor Pokok Wajib Pajak yang wajib dimiliki organisasi untuk mengatur pajak dan biaya layanan. |
| Service Charge (Biaya Layanan) | Biaya tambahan layanan yang dapat dikenakan pada transaksi. |
| Hitung dengan Pajak | Opsi untuk mengaktifkan perhitungan biaya layanan yang disertakan dengan pajak. |
| Nomor Urut Nota | Penomoran otomatis pada nota transaksi yang digunakan sebagai identitas transaksi. |
| Prefix Nota | Awalan teks atau kode pada nomor nota transaksi. |
| Reset Nomor Urut | Pengaturan untuk mengatur ulang nomor urut nota secara harian, mingguan, atau bulanan. |
| Metode Pembayaran | Cara pembayaran yang tersedia dalam sistem transaksi Zycas. |
| Pembayaran Tunai | Metode pembayaran menggunakan uang tunai. |
| Pembayaran Debit/Kredit | Metode pembayaran menggunakan kartu debit atau kredit. |
| Voucher | Metode pembayaran menggunakan voucher sebagai alat tukar transaksi. |
| Hutang | Metode pembayaran dengan sistem pembayaran tertunda. |
| QRIS | Metode pembayaran digital menggunakan kode QR standar nasional. |
| Unggah QRIS | Proses mengunggah gambar kode QRIS ke dalam sistem. |
| Unit Produk | Satuan ukuran produk yang digunakan dalam pencatatan stok dan transaksi. |
| Tambah Unit | Fitur untuk menambahkan data unit produk baru. |
| Edit Unit | Fitur untuk memperbarui data unit produk yang sudah ada. |
| Tag Produk | Label atau penanda untuk mengelompokkan dan mengidentifikasi produk. |
| Tambah Tag | Fitur untuk menambahkan data tag produk baru. |
| Edit Tag | Fitur untuk memperbarui data tag produk yang sudah ada. |
| Varian Produk | Perbedaan karakteristik produk seperti ukuran, rasa, atau warna. |
| Tambah Varian | Fitur untuk menambahkan data varian produk baru. |
| Edit Varian | Fitur untuk memperbarui data varian produk yang sudah ada. |
| Jabatan | Posisi atau peran pengguna dalam organisasi yang menentukan hak akses sistem. |
| Permission Jabatan | Hak akses yang diberikan berdasarkan jabatan pengguna. |
| Jabatan Default | Jabatan bawaan sistem yang tidak dapat diubah oleh pengguna. |
| Pop Up Konfirmasi | Tampilan dialog untuk memastikan tindakan sebelum disimpan atau dibatalkan. |
| Notifikasi Sukses | Pesan sistem yang menandakan suatu proses berhasil dilakukan. |
| Sidebar Menu | Panel navigasi yang muncul setelah menekan ikon hamburger. |
| Ikon Hamburger | Ikon tiga garis yang digunakan untuk membuka sidebar menu. |
