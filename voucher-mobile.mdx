Fitur Voucher pada aplikasi Zycas berguna untuk mengelola atau mengatur voucher mulai dari menambah voucher baru  dan mengedit voucher yang telah terdaftar pada sistem. Voucher nantinya dapat digunakan sebagai potongan pembayaran pada saat melakukan transaksi.

<Frame>
  ![Image](/images/image-293.png)
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Tambah Voucher | Tombol untuk menambahkan voucher |
| 2 | Status Voucher | Tombol untuk filter status voucher |
| 3 | Jangka waktu Voucher | Tombol untuk filter jangka waktu voucher |
| 4 | Pencarian Voucher | Tombol untuk pencarian voucher |
| 5 | Edit voucher | Tombol untuk edit voucher |

## **1.2. Cara Menambah Voucher Baru**

Tambah Voucher adalah fitur yang berfungsi untuk menambah voucher baru ke dalam sistem

<Frame>
  ![Image](/images/image-299.png)
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Nama Voucher | Kolom untuk mengisi nama voucher |
| 2 | Kode Voucher | Kolom untuk mengisi kode voucher |
| 3 | Jangka Waktu | Tombol untuk memilih jangka waktu voucher |
| 4 | Limit Penggunaan | Kolom untuk mengisi limit penggunaan kuota |
| 5 | Tipe Voucher | Tombol untuk memilih tipe voucher |
| 6 | Simpan Voucher | Tombol untuk menyimpan data voucher |

**Berikut cara menambah voucher baru:**

1. Tekan tombol pada halaman voucher 
   <Frame>
     ![Image](/images/image-300.png)
   </Frame>
2. Masukkan nama voucher di kolom nama voucher
   <Frame>
     ![Image](/images/image-301.png)
   </Frame>
3. Anda dapat memasukkan kode voucher di kolom kode voucher
   <Frame>
     ![Image](/images/image-302.png)
   </Frame>
4. Jika kode voucher sudah digunakan maka sistem  akan memberikan peringatan “kode voucher sudah digunakan”
   <Frame>
     ![Image](/images/image-303.png)
   </Frame>
5. Pilih jangka waktu penggunaan voucher di kolom jangka waktu
   <Frame>
     ![Image](/images/image-304.png)
   </Frame>
6. Masukkan jumlah maksimal penggunaan voucher di kolom limit penggunaan
   <Frame>
     ![Image](/images/image-305.png)
   </Frame>
7. Tekan tombol “Tipe Voucher” di kolom Tipe voucher untuk memilih voucher potongan nominal uang atau persentase potongan dari pembelian
   <Frame>
     ![Image](/images/image-306.png)
   </Frame>
8. Setelah menekan tombol akan menampilkan tipe voucher
   <Frame>
     ![Image](/images/image-307.png)
   </Frame>
9. Pilih salah satu tipe voucher
   <Frame>
     ![Frame 966](/images/Frame966.png)
   </Frame>
10. Jika memilih tipe voucher “nominal” masukkan nominal voucher 
    <Frame>
      ![Image](/images/image-308.png)
    </Frame>
11. Jika memilih tipe voucher “persen” masukkan persen voucher
    <Frame>
      ![Image](/images/image-309.png)
    </Frame>
12. Setelah selesai mengisi data voucher, kemudian tekan tombol “simpan voucher”
    <Frame>
      ![Image](/images/image-310.png)
    </Frame>
13. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi simpan voucher
    <Frame>
      ![Image](/images/image-311.png)
    </Frame>
14. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk melanjutkan simpan voucher
    <Frame>
      ![Image](/images/image-312.png)
    </Frame>
15. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan simpan voucher
    <Frame>
      ![Image](/images/image-313.png)
    </Frame>
16. Setelah menekan tombol “Ya, Saya Yakin”,  maka akan menampilkan halaman list voucher serta notifikasi “voucher Berhasil Disimpan”
    <Frame>
      ![Image](/images/image-314.png)
    </Frame>

## **Glosarium**

| **Istilah** | **Deskripsi (Penjelasan dalam Bahasa Indonesia)** |
| :-- | :-- |
| Zycas Mobile | Aplikasi mobile yang digunakan pemilik bisnis untuk mengelola transaksi penjualan, operasional, promo, dan fitur pendukung lainnya. |
| Pengguna (User) | Orang yang menggunakan aplikasi Zycas dengan hak akses tertentu. |
| Owner | Pengguna dengan hak akses penuh untuk mengelola seluruh menu dan fitur dalam aplikasi Zycas. |
| Karyawan | Pengguna dengan hak akses terbatas yang ditentukan oleh owner. |
| Hak Akses | Izin yang diberikan kepada pengguna untuk mengakses menu atau fitur tertentu dalam aplikasi. |
| Play Store | Platform distribusi aplikasi Android tempat pengguna mengunduh aplikasi Zycas. |
| Menu | Kumpulan fitur yang tersedia dalam aplikasi Zycas dan dapat diakses oleh pengguna sesuai hak akses. |
| Voucher | Fitur dalam Zycas yang digunakan untuk mengelola kupon atau diskon sebagai strategi promosi. |
| Modul Voucher | Sistem manajemen voucher yang mencakup pembuatan, pengelolaan, dan distribusi voucher digital. |
| List Voucher | Halaman yang menampilkan daftar voucher yang telah terdaftar dalam sistem. |
| Tambah Voucher | Fitur atau tombol untuk menambahkan voucher baru ke dalam sistem. |
| Edit Voucher | Fitur untuk mengubah data voucher yang sudah terdaftar. |
| Status Voucher | Penanda kondisi voucher (misalnya aktif atau tidak aktif) yang dapat digunakan sebagai filter. |
| Jangka Waktu Voucher | Periode waktu berlaku sebuah voucher. |
| Pencarian Voucher | Fitur untuk mencari voucher berdasarkan kata kunci tertentu. |
| Nama Voucher | Nama identitas voucher yang diisi saat pembuatan atau pengeditan voucher. |
| Kode Voucher | Kode unik voucher yang digunakan pelanggan saat transaksi. |
| Tipe Voucher | Jenis voucher yang menentukan bentuk potongan harga (nominal atau persen). |
| Voucher Nominal | Jenis voucher dengan potongan harga berupa nilai tetap (misalnya Rp10.000). |
| Voucher Persen | Jenis voucher dengan potongan harga berupa persentase (misalnya 10%). |
| Nominal Voucher | Nilai potongan harga yang diberikan pada voucher nominal. |
| Sidebar Menu | Panel navigasi yang muncul setelah menekan ikon hamburger. |
| Ikon Hamburger | Ikon tiga garis yang digunakan untuk membuka sidebar menu. |
| Manajemen Pelanggan | Menu yang berisi pengelolaan data pelanggan termasuk akses ke fitur voucher. |
| Konfirmasi Simpan Voucher | Halaman konfirmasi yang muncul sebelum data voucher disimpan ke sistem. |
| Notifikasi | Pesan sistem yang muncul untuk memberi informasi hasil suatu aksi, seperti “Voucher Berhasil Disimpan”. |
| Filter | Fitur untuk menyaring data voucher berdasarkan kriteria tertentu seperti status atau jangka waktu. |
| Transaksi | Proses pembayaran atau pembelian yang dapat menggunakan voucher sebagai potongan harga. |
| Antarmuka Pengguna (UI) | Tampilan visual aplikasi Zycas yang dirancang agar mudah digunakan. |
