## **1.1. Cara Akses List Member**

**Berikut cara mengakses halaman list member :** 

1. Tekan menu Member di sidebar menu kelola toko
   <Frame>
     <img
       src="/images/Frame-52w3.png"
       alt="Frame 52w3"
       title="Frame 52w3"
       style={{ width:"65%" }}
     />
   </Frame>
2. Setelah menekan menu Member maka akan menampilkan halaman list member
3. Cari member tertentu dengan kata kunci tertentu di kolom cari
   <Frame>
     ![Input (1q21)](/images/Input-\(1q21\).png "Input (1q21)")
   </Frame>
4. Filter member dengan status tertentu
   <Frame>
     ![Input (a20)](/images/Input-\(a20\).png "Input (a20)")
   </Frame>
5. **Ganti konteks toko**
6. Tekan tombol "Toko" di pojok kanan atas halaman
   <Frame>
     ![Nasevbar](/images/Nasevbar.png "Nasevbar")
   </Frame>
7. Setelah menekan tombol, maka akan menampilkan list toko
   <Frame>
     ![Frame2 34](/images/Frame2-34.png "Frame2 34")
   </Frame>
8. Pilih salah satu toko
9. Setelah memilih salah satu toko maka akan menampilkan list member di toko tersebut

## **1.4. Cara Menonaktifkan Member**

Fitur **Menonaktifkan Member** digunakan untuk menonaktifkan anggota ke dalam sistem sehingga pelanggan tersebut tidak akan lagi menjadi member

**Berikut cara menonaktifkan member:**

1. Tekan tombol **Edit Member** di halaman list member
   <Frame>
     ![Button (2sw10)](/images/Button-\(2sw10\).png "Button (2sw10)")
   </Frame>
2. Setelah selesai menekan tombol,  maka akan menampilkan halaman ubah member
3. Tekan tombol “Nonaktifkan Member”
   <Frame>
     ![Framsae 1388](/images/Framsae-1388.png "Framsae 1388")
   </Frame>
4. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi nonaktifkan member
   <Frame>
     ![Alter Dialog (191q2)](/images/alter-dialog-\(191q2\).png "Alter Dialog (191q2)")
   </Frame>
5. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk menonaktifkan member
   <Frame>
     ![Frasme 1366](/images/Frasme-1366.png "Frasme 1366")
   </Frame>
6. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan menonaktifkan member
   <Frame>
     ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
   </Frame>
7. Setelah tekan tombol “Ya, Saya Yakin”, maka akan menampilkan pesan sukses menonaktifkan member
