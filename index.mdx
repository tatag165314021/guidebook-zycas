## **Glosarium**

| **Istilah** | **Deskripsi (Penjelasan dalam Bahasa Indonesia)** |
| :-- | :-- |
| Zycas Mobile | Aplikasi kasir berbasis mobile untuk membantu pengelolaan transaksi, stok, laporan, dan operasional toko secara terpadu. |
| Pengguna (User) | Individu yang menggunakan aplikasi Zycas sesuai dengan hak akses yang diberikan. |
| Owner | Pengguna dengan hak akses penuh untuk mengelola seluruh menu dan fitur dalam aplikasi Zycas. |
| Karyawan | Pengguna dengan hak akses terbatas sesuai izin yang diberikan oleh owner. |
| Hak Akses | Pengaturan izin yang menentukan fitur dan menu yang dapat digunakan oleh pengguna. |
| Dashboard Page | Halaman utama aplikasi Zycas yang menampilkan ringkasan operasional toko secara real-time. |
| Dashboard | Fitur yang menampilkan ringkasan penjualan, stok, produk terlaris, hutang, dan grafik penjualan. |
| Summary Penjualan | Ringkasan data penjualan harian berdasarkan transaksi yang dilakukan kasir. |
| Produk Akan Kadaluarsa | Informasi produk yang mendekati tanggal kedaluwarsa. |
| Produk Kadaluarsa | Informasi produk yang telah melewati tanggal kedaluwarsa. |
| Stok Hampir Habis | Informasi produk dengan jumlah stok mendekati batas minimum. |
| Grafik Penjualan | Tampilan visual berupa grafik untuk menunjukkan tren penjualan dalam periode tertentu. |
| Grafik Penjualan (Hari Ini) | Grafik yang menampilkan data penjualan pada hari berjalan. |
| Grafik Penjualan (Minggu Ini) | Grafik yang menampilkan data penjualan selama minggu berjalan. |
| Grafik Penjualan (Minggu Lalu) | Grafik yang menampilkan data penjualan pada minggu sebelumnya. |
| 5 Produk Terjual Terbanyak Hari Ini | Daftar lima produk dengan jumlah penjualan tertinggi dalam 24 jam terakhir. |
| 5 Produk Terjual Terbanyak (7 Hari ke Belakang) | Daftar lima produk dengan penjualan tertinggi dalam tujuh hari terakhir. |
| 5 Produk Paling Laku | Daftar produk dengan performa penjualan terbaik dalam periode bulanan. |
| 5 Produk Paling Laku (Bulan Ini) | Daftar lima produk terlaris pada bulan berjalan. |
| 5 Produk Paling Laku (Bulan Lalu) | Daftar lima produk terlaris pada bulan sebelumnya. |
| Hutang | Informasi kewajiban pembayaran pelanggan yang belum dilunasi. |
| Hutang (Mendekati Tgl Estimasi Pembayaran) | Daftar hutang yang hampir mencapai tanggal estimasi pembayaran. |
| Hutang (Lewat Tgl Estimasi Pembayaran) | Daftar hutang yang telah melewati tanggal estimasi pembayaran. |
| Estimasi Tanggal Pembayaran | Perkiraan tanggal pelunasan hutang pelanggan. |
| Filter Hutang | Fitur untuk menyaring data hutang berdasarkan status tanggal pembayaran. |
| Rentang Waktu | Periode waktu yang dipilih untuk menampilkan data grafik atau laporan. |
| List Transaksi | Halaman yang menampilkan daftar transaksi penjualan secara detail. |
| List Hutang | Halaman yang menampilkan daftar lengkap transaksi hutang pelanggan. |
| List Selengkapnya | Tombol untuk menampilkan data hutang atau transaksi secara lengkap. |
| Ikon Hamburger | Ikon tiga garis yang digunakan untuk membuka sidebar menu. |
| Sidebar Menu | Panel navigasi yang menampilkan daftar menu utama aplikasi. |
| Dashboard Offline | Kondisi dashboard saat perangkat tidak terhubung ke internet. |
| Mode Offline | Keadaan ketika aplikasi tidak memiliki koneksi internet. |
| Data Terakhir Online | Data terakhir yang tersimpan saat perangkat masih terhubung ke internet. |
| Notifikasi Informasi | Pesan sistem yang memberikan informasi kondisi atau status tertentu pada aplikasi. |
