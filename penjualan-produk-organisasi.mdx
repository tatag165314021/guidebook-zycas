Penjualan Produk menampilkan rincian penjualan berdasarkan setiap produk, termasuk jumlah terjual, total pendapatan per produk, dan performa masing-masing item dalam periode tertentu. Pengguna dapat melihat produk mana yang paling laris, kurang diminati, atau membutuhkan perhatian khusus untuk strategi stok dan pemasaran

## **1.1. Cara Akses Penjualan Produk**

**Berikut cara mengakses menu penjualan produk:**

1. Tekan Penjualan > Penjualan Produk pada list menu di sidebar kelola organisasi
   <Frame>
     ![ONLY ORGANISASI (1sdfswa8)](/images/ONLY-ORGANISASI-\(1sdfswa8\).png "ONLY ORGANISASI (1sdfswa8)")
   </Frame>
2. Setelah menekan menu Penjualan Produk maka akan menampilkan halaman Penjualan Produk
3. Tekan tombol “Periode” untuk filter data laporan penjualan produk
   <Frame>
     ![Input (2sdfsdfs6)](/images/Input-\(2sdfsdfs6\).png "Input (2sdfsdfs6)")
   </Frame>
4. **Jika memilih filter mingguan klik tab “Mingguan”**
   <Frame>
     ![Popover (aasdwaaww)](/images/popover-\(aasdwaaww\).png "Popover (aasdwaaww)")
   </Frame>
5. Pilih minggu dengan range tertentu
6. Setelah memilih minggu, tekan tombol “Terapkan Periode”
7. Setelah menekan tombol maka akan menampilkan data sesuai minggu di filter
8. **Jika memilih filter bulanan klik tab “Bulanan”**
   <Frame>
     ![Popover (8sdsdfwwaw)](/images/popover-\(8sdsdfwwaw\).png "Popover (8sdsdfwwaw)")
   </Frame>
9. Pilih bulan dengan range tertentu
10. Setelah memilih bulan, tekan tombol “Terapkan Periode”
11. Setelah menekan tombol maka akan menampilkan data sesuai bulan di filter
12. **Jika memilih filter kuartal klik tab “Kuartal”**
    <Frame>
      ![Popover (9sdfesdes)](/images/popover-\(9sdfesdes\).png "Popover (9sdfesdes)")
    </Frame>
13. Pilih kuartal dengan range tertentu
14. Setelah memilih kuartal, tekan tombol “Terapkan Periode”
15. Setelah menekan tombol maka akan menampilkan data sesuai kuartal di filter
16. Tekan tombol “Nama Produk” untuk filter data laporan detail penjualan dari produk tertentu
    <Frame>
      ![Input (2erwedses5)](/images/Input-\(2erwedses5\).png "Input (2erwedses5)")
    </Frame>
17. Tekan tombol “Nama Toko” untuk filter data laporan ringkasan penjualan dari toko tertentu
    <Frame>
      ![Inputfiltertoko](/images/Inputfiltertoko.png "Inputfiltertoko")
    </Frame>
