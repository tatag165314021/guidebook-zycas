## **1.1. Cara Akses Master Data Jabatan**

**Berikut cara mengakses menu master data jabatan:**

1. Tekan menu Jabatan pada list menu di sidebar kelola organisasi
   <Frame>
     ![ONLY ORGANISASI (ddedww7)](/images/ONLY-ORGANISASI-\(ddedww7\).png "ONLY ORGANISASI (ddedww7)")
   </Frame>
2. Sistem akan menampilkan halaman **List Master Data Jabatan**

## **1.2. Cara Menambah Jabatan**

**Berikut cara menambah jabatan:**

1. Tekan tombol “Tambah jabatan” di halaman list jabatan
   <Frame>
     ![Button (14derwdfg)](/images/Button-\(14derwdfg\).png "Button (14derwdfg)")
   </Frame>
2. Setelah menekan tombol, maka akan menampilkan halaman input jabatan
3. Masukkan nama jabatan  di kolom nama jabatan
   <Frame>
     ![Input (deqweqd8)](/images/Input-\(deqweqd8\).png "Input (deqweqd8)")
   </Frame>
4. Tekan tombol permission untuk mengaktifkan hak akses jabatan
   <Frame>
     ![Sectiosfwfwen](/images/Sectiosfwfwen.png "Sectiosfwfwen")
   </Frame>
5. Setelah selesai mengisi jabatan, kemudian tekan tombol “Simpan jabatan ”
   <Frame>
     ![Button (1dwee3)](/images/Button-\(1dwee3\).png "Button (1dwee3)")
   </Frame>
6. Setelah selesai menekan tombol, maka akan menampilkan halaman konfirmasi simpan jabatan 
   <Frame>
     ![Alter Dialog (xcsedw9)](/images/alter-dialog-\(xcsedw9\).png "Alter Dialog (xcsedw9)")
   </Frame>
7. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk menyimpan data jabatan 
   <Frame>
     ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
   </Frame>
8. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan 
   <Frame>
     ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
   </Frame>
9. Setelah tekan tombol “Ya, Saya Yakin”, maka akan menampilkan pesan sukses simpan jabatan

## **1.3. Cara Mengubah Jabatan**

**Berikut cara mengubah jabatan:**

1. Tekan tombol “Detail Jabatan” di halaman list jabatan 
   <Frame>
     ![Button (1sdfewrw2)](/images/Button-\(1sdfewrw2\).png "Button (1sdfewrw2)")
   </Frame>
2. Setelah menekan tombol, maka akan menampilkan halaman input jabatan
3. Ubah nama jabatan di kolom nama jabatan
   <Frame>
     ![Input (deqweqd8)](/images/Input-\(deqweqd8\).png "Input (deqweqd8)")
   </Frame>
4. Tekan tombol permission untuk mengaktifkan hak akses jabatan
   <Frame>
     ![Sectiosfwfwen](/images/Sectiosfwfwen.png "Sectiosfwfwen")
   </Frame>
5. Setelah selesai mengubah jabatan, kemudian tekan tombol “Simpan jabatan”
   <Frame>
     ![Button (1dwee3)](/images/Button-\(1dwee3\).png "Button (1dwee3)")
   </Frame>
6. Setelah selesai menekan tombol, maka akan menampilkan halaman konfirmasi simpan jabatan 
   <Frame>
     ![Alter Dialog (xcsedw9)](/images/alter-dialog-\(xcsedw9\).png "Alter Dialog (xcsedw9)")
   </Frame>
7. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk menyimpan data  jabatan 
   <Frame>
     ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
   </Frame>
8. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan 
   <Frame>
     ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
   </Frame>
9. Setelah tekan tombol “Ya, Saya Yakin”, maka akan menampilkan pesan sukses simpan jabatan
