## **1.1. Cara Melakukan Login Employee**

Menu **Login** adalah menu yang berisi form untuk masuk ke aplikasi Zycas untuk user employee/staff.

<Frame>
  ![Loginse2 (1)](/images/Loginse2-\(1\).png "Loginse2 (1)")
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Username | Kolom untuk mengisi username pengguna |
| 2 | Lupa Organisasi | Tombol  untuk mendapatkan informasi ID Organisasi |
| 3 | ID Organisasi | Tombol untuk mengisi ID Organisasi |
| 4 | Password | Kolom untuk mengisi password pengguna |
| 5 | Login | Tombol untuk memproses login akun |
| 6 | Lupa Password | Tombol untuk memproses reset password |

**Berikut merupakan tahapan login akun:**

1. Akses link Zycas Desktop di browser untuk diarahkan ke halaman login
2. Pilih tab “Pegawai”
   <Frame>
     ![Bottoswm](/images/bottoswm.png "Bottoswm")
   </Frame>
3. Masukkan username anda di kolom username
   <Frame>
     ![Ise4nput](/images/Ise4nput.png "Ise4nput")
   </Frame>
4. Masukkan id organisasi di kolom id organisasi
   <Frame>
     ![Ie4d Org](/images/Ie4D-Org.png "Ie4d Org")
   </Frame>
5. Masukkan password anda di kolom password
   <Frame>
     ![Password](/images/Password.png "Password")
   </Frame>
6. Setelah selesai mengisi data login, kemudian tekan tombol “Login”
   <Frame>
     ![Button](/images/Button.png "Button")
   </Frame>
7. **Setelah menekan tombol "Login", jika data valid dan user memiliki akses kelola organisasi dan kelola toko sekaligus maka akan menampilkan halaman onboarding pilih kelola**
   <Frame>
     ![Onboardin2qg Pilih Kelola](/images/Onboardin2qg-Pilih-Kelola.jpg "Onboardin2qg Pilih Kelola")
   </Frame>
8. **Jika memilih kelola toko di halaman onboarding pilih kelola  (ikuti panduan nomor 9 - 16)**
9. Tekan tombol "Kelola Toko"
   <Frame>
     ![Sectio3esn (3)](/images/Sectio3esn-\(3\).png "Sectio3esn (3)")
   </Frame>
10. **Jika user memiliki hak akses hanya satu toko maka akan langsung diarahkan ke dashboard toko tersebut**
11. **Jika user memiliki hak akses lebih dari satu toko, maka akan diarahkan ke halaman list toko**
    <Frame>
      ![Linkesw2d Device](/images/Linkesw2d-Device.jpg "Linkesw2d Device")
    </Frame>
12. Tekan tombol "Masuk Dashboard" di salah satu toko
    <Frame>
      ![Butto24en (3)](/images/Butto24en-\(3\).png "Butto24en (3)")
    </Frame>
13. Setelah menekan tombol maka akan menampilkan halaman konfirmasi pilih toko
    <Frame>
      ![Alter Dialos2g (1)](/images/alter-dialos2g-\(1\).png "Alter Dialos2g (1)")
    </Frame>
14. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk masuk ke dashboard toko
    <Frame>
      ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
    </Frame>
15. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan masuk ke dashboard toko
    <Frame>
      ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
    </Frame>
16. Setelah tekan tombol “Ya, Saya Yakin”, maka akan diarahkan ke dashboard toko
17. **Jika memilih kelola organisasi di halaman onboarding pilih kelola (ikuti panduan nomor 18 - 19)**
18. Tekan tombol "Kelola Organisasi"
    <Frame>
      ![Section23w (4)](/images/Section23w-\(4\).png "Section23w (4)")
    </Frame>
19. Setelah menekan tombol, maka akan diarahkan ke halaman dashboard organisasi
