---
title: "Pengaturan Toko Kelola Toko"
---

Fitur **Pengaturan Toko** digunakan untuk mengelola pengaturan kasir dan beberapa konfigurasi tambahan pada sistem, seperti nilai persen pajak, biaya layanan, nomor urut nota, hingga unggah QRIS.

<Frame>
  ![Pengatura34sn](/images/Pengatura34sn.jpg "Pengatura34sn")
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Ubah Toko | Tombol untuk mengubah data toko |
| 2 | Cek Lokasi | Tombol untuk melihat lokasi toko |
| 3 | Edit Pajak | Tombol untuk mengedit pajak |
| 4 | Ubah Service Change | Tombol untuk mengedit service change |
| 5 | Atur Nomor Urut Data | Tombol untuk mengatur nomor urut data |
| 6 | Tampilkan No Antrian Di Nota | Tombol untuk mengatur tampilannya no antrian di nota |
| 7 | Aktifkan Metode Pembayaran | Tombol untuk mengatur metode pembayaran |

## **1.1. Cara Akses Pengaturan Toko**

**Berikut cara mengakses halaman pengaturan toko:** 

1. Tekan menu pengaturan di sidebar menu kelola toko
   <Frame>
     ![Frame 51s3](/images/Frame-51s3.png "Frame 51s3")
   </Frame>
2. Setelah menekan tombol, maka akan menampilkan halaman pengaturan toko
3. **Ganti konteks toko**
4. Tekan tombol "Toko" di pojok kanan atas halaman
   <Frame>
     ![Nasevbar](/images/Nasevbar.png "Nasevbar")
   </Frame>
5. Setelah menekan tombol, maka akan menampilkan list toko
   <Frame>
     ![Frame2 34](/images/Frame2-34.png "Frame2 34")
   </Frame>
6. Pilih salah satu toko
7. Setelah memilih salah satu toko maka akan menampilkan pengaturan di toko tersebut

## **1.2. Cara Mengubah Persen Pajak**

**Berikut cara mengakses menu edit pajak:**

1. Tekan tombol “Ubah Pajak” di halaman Pengaturan Toko
   <Frame>
     ![Frame 2qa37872](/images/Frame-2qa37872.png "Frame 2qa37872")
   </Frame>
2. Setelah menekan tombol, maka akan menampilkan halaman ubah pajak
   <Frame>
     ![Alter Dialo1g (9)](/images/alter-dialo1g-\(9\).png "Alter Dialo1g (9)")
   </Frame>
3. Ubah persen pajak di kolom persen pajak
   <Frame>
     ![Input (1f4)](/images/Input-\(1f4\).png "Input (1f4)")
   </Frame>
4. Setelah selesai mengubah persen pajak, kemudian tekan tombol “Simpan Pajak”
   <Frame>
     ![Button (1qar4)](/images/Button-\(1qar4\).png "Button (1qar4)")
   </Frame>
5. Jika organisasi sudah memiliki NPWP, maka akan menampilkan halaman konfirmasi ubah pajak
   <Frame>
     ![Alter Dialo364g (10)](/images/alter-dialo364g-\(10\).png "Alter Dialo364g (10)")
   </Frame>
6. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk menyimpan data pajak
   <Frame>
     ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
   </Frame>
7. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan 
   <Frame>
     ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
   </Frame>
8. Setelah tekan tombol “Ya, Saya Yakin”, maka akan menampilkan pesan sukses mengubah pajak

## **1.3. Cara Mengubah Biaya Layanan**

**Berikut cara mengakses menu edit biaya layanan:**

1. Tekan tombol “Ubah Service Charge” di halaman Pengaturan Toko
   <Frame>
     ![Frame A237875](/images/Frame-a237875.png "Frame A237875")
   </Frame>
2. Setelah menekan tombol, maka akan menampilkan halaman ubah biaya layanan
3. Ubah persen biaya layanan di kolom persen service charge
   <Frame>
     ![Inpuast (15)](/images/Inpuast-\(15\).png "Inpuast (15)")
   </Frame>
4. Tekan tombol “Kena Pajak PPN” untuk dapat mengaktifkan biaya layanan disertakan dengan pajak
   <Frame>
     ![Switcah](/images/switcah.png "Switcah")
   </Frame>
5. Setelah selesai mengubah persen biaya layanan, kemudian tekan tombol “Simpan Service Charge”
6. Jika organisasi sudah memiliki NPWP, maka akan menampilkan halaman konfirmasi ubah biaya layanan
   <Frame>
     ![Alter Dialoaqg (12)](/images/alter-dialoaqg-\(12\).png "Alter Dialoaqg (12)")
   </Frame>
7. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk menyimpan data biaya layanan
   <Frame>
     ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
   </Frame>
8. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan 
   <Frame>
     ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
   </Frame>
9. Setelah tekan tombol “Ya, Saya Yakin”, maka akan menampilkan pesan sukses mengubah biaya layanan

## **1.4. Cara Mengubah No Urut Nota**

**Berikut cara mengakses menu edit no urut nota:**

1. Tekan tombol “Atur No. Urut” di halaman Pengaturan Toko
   <Frame>
     ![Framsae 237873](/images/Framsae-237873.png "Framsae 237873")
   </Frame>
2. Setelah menekan tombol, maka akan menampilkan halaman ubah no urut
3. Ubah prefix di kolom prefix
   <Frame>
     ![Input (1saw6)](/images/Input-\(1saw6\).png "Input (1saw6)")
   </Frame>
4. Ubah no urut awal di kolom no urut awal
   <Frame>
     ![Input (1was7)](/images/Input-\(1was7\).png "Input (1was7)")
   </Frame>
5. Pilih jumlah hari reset no urut nota
   <Frame>
     ![Inputqas (18)](/images/Inputqas-\(18\).png "Inputqas (18)")
   </Frame>
6. Anda dapat memilih jumlah hari reset no urut nota untuk harian, mingguan atau bulanan
7. Setelah selesai mengubah no urut nota, kemudian tekan tombol “Simpan No Urut Nota”
8. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi ubah no urut nota
   <Frame>
     ![Alter Dialog1q (13)](/images/alter-dialog1q-\(13\).png "Alter Dialog1q (13)")
   </Frame>
9. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk menyimpan data  no urut nota
   <Frame>
     ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
   </Frame>
10. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan 
    <Frame>
      ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
    </Frame>
11. Setelah tekan tombol “Ya, Saya Yakin”, maka akan menampilkan pesan sukses mengubah  no urut nota

## **1.5. Cara Mengaktifkan Cetak No Antiran**

B**erikut cara mengakses menu aktifkan cetak no antrian:**

1. Tekan tombol “Tampilkan di nota” untuk dapat mengaktifkan no antrian tercetak di nota pembeli di halaman Pengaturan Toko
   <Frame>
     ![Frame 237ty874](/images/Frame-237ty874.png "Frame 237ty874")
   </Frame>

## **1.6. Cara Mengaktifkan Metode Pembayaran**

**Berikut cara mengakses menu metode pembayaran:**

1. Gulirkan layar kebawah di halaman Pengaturan Toko untuk melihat metode pembayaran yang aktif
   <Frame>
     ![Frame 23787gh6](/images/Frame-23787gh6.png "Frame 23787gh6")
   </Frame>
2. Tekan tombol “Tunai” untuk dapat mengaktifkan atau menonaktifkan metode pembayaran tunai
3. Tekan tombol “Debit/Kredit” untuk dapat mengaktifkan atau menonaktifkan metode pembayaran debit/kredit
4. Tekan tombol “Voucher” untuk dapat mengaktifkan atau menonaktifkan metode pembayaran voucher
5. Tekan tombol “Hutang” untuk dapat mengaktifkan metode pembayaran hutang
6. Tekan tombol “QRIS” untuk dapat mengaktifkan metode pembayaran QRIS
7. Unggah gambar kode QRIS dengan tekan tombol “Unggah Gambar QRIS”
   <Frame>
     ![Input (1sa19)](/images/Input-\(1sa19\).png "Input (1sa19)")
   </Frame>

## **1.7. Cara Mengubah Data Toko**

B**erikut cara mengakses menu ubah data toko:**

1. Tekan tombol “Ubah Toko” di halaman Pengaturan Toko di Kelola Toko

<Frame>
  ![Frame 23793io9](/images/Frame-23793io9.png "Frame 23793io9")
</Frame>

2. Setelah menekan tombol, maka akan menampilkan halaman ubah toko

<Frame>
  ![Pengatur12asan](/images/Pengatur12asan.jpg "Pengatur12asan")
</Frame>

3. Tekan tombol "Unggah Logo" di kolom logo untuk mengunggah logo toko

<Frame>
  ![Inpu12at](/images/Inpu12at.png "Inpu12at")
</Frame>

4. Ubah tipe toko di kolom tipe toko
5. Ubah Jenis toko di kolom jenis toko

<Frame>
  ![Input (uj9)](/images/Input-\(uj9\).png "Input (uj9)")
</Frame>

6. Ubah nama toko di kolom nama toko

<Frame>
  ![Input (7wrs)](/images/Input-\(7wrs\).png "Input (7wrs)")
</Frame>

7. Ubah no whatsapp toko di kolom no whatsapp

<Frame>
  ![WA](/images/WA.png "WA")
</Frame>

8. Ubah lokasi toko di kolom lokasi
9. Ubah alamat toko di kolom alamat

<Frame>
  ![Inpuvbt (12)](/images/Inpuvbt-\(12\).png "Inpuvbt (12)")
</Frame>

10. Setelah selesai mengubah data toko, tekan tombol "Simpan Toko"

<Frame>
  ![Button (1q2)](/images/Button-\(1q2\).png "Button (1q2)")
</Frame>

11. Setelah menekan tombol, maka akan menampilkan pop up konfirmasi simpan toko

<Frame>
  ![Alter32a Dialog](/images/alter32a-dialog.png "Alter32a Dialog")
</Frame>

12. Tekan tombol "Tidak" untuk membatalkan proses simpan perubahan data toko

<Frame>
  ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
</Frame>

13. Tekan tombol "Ya, Saya Yakin" untuk memproses simpan perubahan data toko

<Frame>
  ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
</Frame>

14. Setelah menekan tombol "Ya, Saya Yakin" maka akan menampilkan pesan sukses ubah data toko
