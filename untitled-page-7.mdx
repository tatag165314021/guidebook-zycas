Fitur Voucher pada aplikasi Zycas berguna untuk mengelola atau mengatur voucher mulai dari menambah voucher baru  dan mengedit voucher yang telah terdaftar pada sistem. Voucher nantinya dapat digunakan sebagai potongan pembayaran atau pemberian produk gratis ketika melakukan transaksi.

<Frame>
  ![Android Expanded 358](/images/Android-Expanded---358.png)
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Tambah Voucher | Tombol untuk menambahkan voucher |
| 2 | Status Voucher | Tombol untuk filter status voucher |
| 3 | Jangka waktu Voucher | Tombol untuk filter jangka waktu voucher |
| 4 | Pencarian Voucher | Tombol untuk pencarian voucher |
| 5 | Edit voucher | Tombol untuk edit voucher |
| 6 | Detail Voucher | Tombol untuk mengakses detail voucher |

## **1.2. Cara Menambah Voucher Baru**

Tambah Voucher adalah fitur yang berfungsi untuk menambah voucher baru ke dalam sistem

<Frame>
  ![Android Expanded 409](/images/Android-Expanded---409.png)
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Nama Voucher | Kolom untuk mengisi nama voucher |
| 2 | Kode Voucher | Kolom untuk mengisi kode voucher |
| 3 | Jangka Waktu | Tombol untuk memilih jangka waktu voucher |
| 4 | Tipe Limit | Tombol untuk memilih tipe limit penggunaan voucher di lingkup organisasi, toko, atau member |
| 5 | Limit Penggunaan | Kolom untuk mengisi kuota penggunaan voucher |
| 6 | Tipe Voucher | Tombol untuk memilih tipe voucher potongan nominal, persentase, atau produk gratis |
| 7 | Jumlah Potongan | Kolom untuk mengisi nominal atau presentase potongan  transaksi ketika menggunakan voucher |
| 8 | Pilih Produk Gratis | Tombol untuk memilih dan mengisi jumlah produk gratis yang didapat ketika menggunakan voucher |
| 9 | Maksimal Diskon Hingga | Kolom untuk mengisi nominal maksimal potongan yang didapatkan ketika menggunakan voucher |
| 10 | Minimum Transaksi | Kolom untuk mengisi nominal minimum transaksi sebagai syarat penggunaan voucher |
| 11 | Syarat Pembelian Produk Tertentu | Tombol untuk memilih produk tertentu yang harus dibeli pelanggan sebagai syarat penggunaan voucher |
| 12 | Metode Pembayaran | Tombol untuk memilih metode pambayaran tertentu yang dapat menggunakan voucher |
| 13 | Voucher Ekslusif | Tombol untuk mengaktifkan voucher dapat dikombinasikan dengan voucher lainnya |
| 14 | Simpan Voucher | Tombol untuk menyimpan data voucher |

**Berikut cara menambah voucher baru:**

1. Tekan tombol pada halaman list voucher 
   <Frame>
     ![Image](/images/image-300.png)
   </Frame>
2. Masukkan nama voucher di kolom nama voucher
   <Frame>
     ![Image](/images/image-301.png)
   </Frame>
3. Anda dapat memasukkan kode voucher di kolom kode voucher
   <Frame>
     ![Image](/images/image-302.png)
   </Frame>
4. Jika kode voucher sudah digunakan maka sistem  akan memberikan peringatan “kode voucher sudah digunakan”
   <Frame>
     ![Image](/images/image-2786.png)
   </Frame>
5. Pilih jangka waktu penggunaan voucher di kolom jangka waktu
   <Frame>
     ![Image](/images/image-304.png)
   </Frame>
6. Tekan tombol "Tipe Limit" di kolom limit penggunaan untuk memilih tipe cakupan penggunaan voucher per toko atau per member

<Frame>
  ![Image](/images/image-2775.png)
</Frame>

7. Masukkan jumlah kuota penggunaan voucher di kolom jumlah limit

<Frame>
  ![Image](/images/image-2776.png)
</Frame>

8. Tekan tombol “Tipe Voucher” di kolom Tipe voucher untuk memilih voucher potongan nominal uang, persentase potongan dari pembelian, atau produk gratis

<Frame>
  ![Image](/images/image-2777.png)
</Frame>

9. **Jika memilih tipe voucher “nominal”** masukkan nominal voucher 
   <Frame>
     ![Image](/images/image-308.png)
   </Frame>
10. **Jika memilih tipe voucher “persen”** masukkan persen voucher
    <Frame>
      ![Image](/images/image-309.png)
    </Frame>
11. Masukkan nominal maksimal diskon voucher di kolom maks diskon hingga jika voucher memiliki maksimal diskon

<Frame>
  ![Image](/images/image-2778.png)
</Frame>

12. **Jika memilih tipe voucher “produk gratis”** tekan tombol "Pilih Produk yang Didapatkan"

<Frame>
  ![Image](/images/image-2779.png)
</Frame>

13. Pilih salah satu produk gratis untuk voucher tersebut di list produk

<Frame>
  ![Image](/images/image-2780.png)
</Frame>

14. Tekan tombol "Pilih Produk" setelah selesai memilih produk

<Frame>
  ![Image](/images/image-2781.png)
</Frame>

15. Masukkan jumlah produk gratis yang didapatkan

<Frame>
  ![Image](/images/image-2782.png)
</Frame>

16. Masukkan nominal minimum transaksi di kolom minimum transaksi jika voucher terdapat syarat minimum pembelian

<Frame>
  ![Image](/images/image-2783.png)
</Frame>

17. Jika voucher memiliki syarat pembelian produk tertentu tekan tombol "Pilih Produk"

<Frame>
  ![Image](/images/image-2788.png)
</Frame>

18. Pilih salah satu produk yang harus dibeli sebagai syarat penggunaan voucher di list produk

<Frame>
  ![Image](/images/image-2789.png)
</Frame>

19. Tekan tombol "Pilih Produk" setelah selesai memilih produk

<Frame>
  ![Image](/images/image-2790.png)
</Frame>

20. Tekan tombol "Metode Pembayaran" untuk memilih metode pembayaran tertentu sebagai syarat menggunakan voucher

<Frame>
  ![Image](/images/image-2784.png)
</Frame>

21. Pilih salah satu atau beberapa metode pembayaran

<Frame>
  ![Image](/images/image-2774.png)
</Frame>

22. Tekan tombol "Pilih Metode Pembayaran" setelah selesai pilih metode pembayaran

<Frame>
  ![Image](/images/image-2773.png)
</Frame>

23. Aktifkan atau nonaktifkan voucher dapat digunakan bersamaan dengan voucher lain ketika transaksi

<Frame>
  ![Image](/images/image-2772.png)
</Frame>

24. Setelah selesai mengisi data voucher, kemudian tekan tombol “simpan voucher”

<Frame>
  ![Image](/images/image-310.png)
</Frame>

25. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi simpan voucher

<Frame>
  ![Image](/images/image-311.png)
</Frame>

26. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk melanjutkan simpan voucher

<Frame>
  ![Image](/images/image-312.png)
</Frame>

27. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan simpan voucher

<Frame>
  ![Image](/images/image-313.png)
</Frame>

28. Setelah menekan tombol “Ya, Saya Yakin”,  maka akan menampilkan halaman list voucher serta notifikasi “voucher Berhasil Disimpan”

<Frame>
  ![Image](/images/image-2769.png)
</Frame>

## 1.3. Cara Edit Voucher

Edit Voucher adalah fitur yang berfungsi untuk mengubah data voucher yang sudah pernah didaftarkan atau ditambahkan

<Frame>
  ![Image](/images/image-2754.png)
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Nama Voucher | Tombol untuk memilih tanggal pengembalian |
| 2 | Kode Voucher | Tombol untuk mengisi kode voucher |
| 3 | Jangka Waktu | Tombol untuk mengisi jangka waktu voucher |

**Berikut cara mengakses edit voucher:**

1. Tekan tombol aksi (3 titik) pada salah satu voucher di halaman list voucher 

<Frame>
  ![Frame 1016](/images/Frame-1016.png)
</Frame>

2. Setelah menekan tombol, maka akan menampilkan opsi aksi

<Frame>
  ![Frame 1205](/images/Frame-1205.png)
</Frame>

3. Tekan tombol "Ubah Informasi Voucher"

<Frame>
  ![Frame 1369](/images/Frame-1369.jpg)
</Frame>

4. Ubah nama voucher di kolom nama voucher

<Frame>
  ![Image](/images/image-315.png)
</Frame>

5. Anda dapat mengubah kode voucher di kolom kode voucher

<Frame>
  ![Image](/images/image-316.png)

7. Ubah jangka waktu voucher
