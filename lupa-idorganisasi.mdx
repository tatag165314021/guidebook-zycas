**Berikut merupakan tahapan mendapatkan broadcast id organisasi:**

1. Pilih tab “Pegawai” di halaman login
   <Frame>
     ![Bottoswm](/images/bottoswm.png "Bottoswm")
   </Frame>
2. Tekan tombol “Lupa Organisasi?”
   <Frame>
     ![Lupa Organisas2si](/images/Lupa-Organisas2si_.png "Lupa Organisas2si")
   </Frame>
3. Setelah menekan tombol, maka akan menampilkan halaman lupa organisasi
4. Masukkan no whatsapp anda di kolom no whatsapp
   <Frame>
     ![WA](/images/WA.png "WA")
   </Frame>
5. Setelah selesai mengisi no whatsapp, kemudian tekan tombol “Kirim Permintaan”
   <Frame>
     ![Button (s24)](/images/Button-\(s24\).png "Button (s24)")
   </Frame>
6. Setelah menekan tombol, maka akan menampilkan pesan sukses permintaan broadcast id organisasi dan diarahkan ke halaman login, informasi organisasi akan dikirim ke no whatsapp user
