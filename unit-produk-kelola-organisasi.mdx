## **1.1. Cara Akses Master Data Unit**

**Berikut cara mengakses menu master data unit:**

1. Tekan menu Unit pada list menu di sidebar kelola organisasi
   <Frame>
     ![ONLY ORGANISASI (5sdafwfrwe)](/images/ONLY-ORGANISASI-\(5sdafwfrwe\).png "ONLY ORGANISASI (5sdafwfrwe)")
   </Frame>
2. Sistem akan menampilkan halaman **List Master Data Unit Produk**

## **1.2. Cara Menambah Unit Produk**

**Berikut cara menambah unit produk:**

1. Tekan tombol “Tambah Unit” di halaman list unit produk
   <Frame>
     ![Button (8asyvdgsdr)](/images/Button-\(8asyvdgsdr\).png "Button (8asyvdgsdr)")
   </Frame>
2. Setelah menekan tombol, maka akan menampilkan halaman input unit
3. Masukkan nama unit di kolom nama unit
   <Frame>
     ![Input (5gg4y34)](/images/Input-\(5gg4y34\).png "Input (5gg4y34)")
   </Frame>
4. Setelah selesai mengisi unit, kemudian tekan tombol “Simpan Unit”
   <Frame>
     ![Button (9sdfsef)](/images/Button-\(9sdfsef\).png "Button (9sdfsef)")
   </Frame>
5. Setelah selesai menekan tombol, maka akan menampilkan halaman konfirmasi simpan unit produk
   <Frame>
     ![Alter Dialog (sdfsdfwe5)](/images/alter-dialog-\(sdfsdfwe5\).png "Alter Dialog (sdfsdfwe5)")
   </Frame>
6. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk menyimpan data  unit produk
   <Frame>
     ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
   </Frame>
7. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan 
   <Frame>
     ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
   </Frame>
8. Setelah tekan tombol “Ya, Saya Yakin”, maka akan menampilkan pesan sukses simpan unit

## **1.3. Cara Mengubah Unit Produk**

**Berikut cara mengubah unit produk:**

1. Tekan tombol “Edit Unit” di halaman list unit produk
   <Frame>
     ![Button (2h473)](/images/Button-\(2h473\).png "Button (2h473)")
   </Frame>
2. Setelah menekan tombol, maka akan menampilkan halaman input unit
3. Ubah nama unit  di kolom nama unit
   <Frame>
     ![Input (5gg4y34)](/images/Input-\(5gg4y34\).png "Input (5gg4y34)")
   </Frame>
4. Setelah selesai mengubah unit, kemudian tekan tombol “Simpan Unit”
   <Frame>
     ![Button (9sdfsef)](/images/Button-\(9sdfsef\).png "Button (9sdfsef)")
   </Frame>
5. Setelah selesai menekan tombol, maka akan menampilkan halaman konfirmasi simpan unit produk
   <Frame>
     ![Alter Dialog (sdfsdfwe5)](/images/alter-dialog-\(sdfsdfwe5\).png "Alter Dialog (sdfsdfwe5)")
   </Frame>
6. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk menyimpan data  unit produk
   <Frame>
     ![Button2q (1)](/images/Button2q-\(1\).png "Button2q (1)")
   </Frame>
7. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan 
   <Frame>
     ![Button2sa (2)](/images/Button2sa-\(2\).png "Button2sa (2)")
   </Frame>
8. Setelah tekan tombol “Ya, Saya Yakin”, maka akan menampilkan pesan sukses simpan unit
