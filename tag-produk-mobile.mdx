## **1.1. Cara Akses Master Data Tag Produk**

**Berikut cara mengakses menu master data tag produk:**

1. Tekan ikon tiga garis di pojok kiri atas

<Frame>
  ![Frame 1332](/images/Frame-1332.png "Frame 1332")
</Frame>

2. Setelah menekan ikon hamburger, maka akan menampilkan sidebar list menu

  <img
    src="/images/800-PsX-(2).png"
    alt="800 Ps X (2)"
    title="800 Ps X (2)"
    style={{ width:"45%" }}
  />
</Frame>

3. Tekan menu Master Data pada list menu

<Frame>
  ![Frame 1a186](/images/Frame-1a186.png "Frame 1a186")
</Frame>

4. Setelah tekan menu Master Data, maka akan menampilkan list sub menu Master Data

<Frame>
  ![Frame 139q1](/images/Frame-139q1.png "Frame 139q1")
</Frame>

5. Lalu tekan menu Tags Produk pada list sub menu Master Data

<Frame>
  ![Framyie 1180](/images/Framyie-1180.png "Framyie 1180")
</Frame>

6. Sistem akan menampilkan halaman **List Master Data Tag Produk**

## **1.2. Cara Menambah Tag Produk**

**Berikut cara menambah tags Produk**

1. Tekan tombol “Tambah Tag” di halaman list tags produk

<Frame>
  ![Frame 96o1](/images/Frame-96o1.png "Frame 96o1")
</Frame>

2. Setelah menekan tombol, maka akan menampilkan halaman input tags

<Frame>
  ![Android Expasnded 422](/images/Android-Expasnded---422.png "Android Expasnded 422")
</Frame>

3. Masukkan nama tag di kolom nama tags

<Frame>
  ![Frame 1457 (1y)](/images/Frame-1457-\(1y\).png "Frame 1457 (1y)")
</Frame>

4. Setelah selesai mengisi tags, kemudian tekan tombol “Simpan Tag”

<Frame>
  ![Frame 141q2](/images/Frame-141q2.png "Frame 141q2")
</Frame>

5. Setelah selesai menekan tombol, maka akan menampilkan halaman konfirmasi simpan tag produk

<Frame>
  ![Frame 1336w (1)](/images/Frame-1336w-\(1\).png "Frame 1336w (1)")
</Frame>

6. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk menyimpan data  tag produk

<Frame>
  <img
    src="/images/image-21.png"
    alt="Image 21"
    title="Image 21"
    style={{ width:"55%" }}
  />
</Frame>

7. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan

8. Setelah tekan tombol “Ya, Saya Yakin”, maka akan menampilkan pesan sukses simpan tag

| Pengguna (User) | Individu yang menggunakan aplikasi Zycas dengan hak akses tertentu. |
| Owner | Pengguna dengan hak akses penuh untuk mengelola seluruh menu dan konfigurasi sistem. |
| Karyawan | Pengguna dengan hak akses terbatas sesuai pengaturan dari owner. |
| Hak Akses | Izin yang menentukan menu dan fitur yang dapat digunakan oleh pengguna. |

| Foundational Settings | Pengaturan dasar sistem yang menjadi fondasi bagi modul operasional lainnya. |
| Backbone Sistem | Struktur utama sistem yang menopang seluruh konfigurasi dan proses aplikasi. |
| POS (Point of Sale) | Modul kasir yang menggunakan data dari Master Data untuk proses transaksi. |
| Edit Pajak | Fitur untuk mengubah persentase pajak yang digunakan dalam transaksi. |
| Persen Pajak | Nilai persentase pajak yang dikenakan pada transaksi penjualan. |
