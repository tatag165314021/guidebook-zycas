## **7.1. Cara Akses Laporan Kasir**

**Berikut cara mengakses menu laporan kasir:**

1. Tekan menu Laporan Kasir pada list menu di sidebar kelola organisasi
   <Frame>
     ![ONLY ORGANISASI (11cvsdfsc)](/images/ONLY-ORGANISASI-\(11cvsdfsc\).png "ONLY ORGANISASI (11cvsdfsc)")
   </Frame>
2. Setelah menekan menu Laporan Kasir maka akan menampilkan halaman Laporan Kasir
3. Tekan tombol “Range Tanggal Buka Kasir” untuk filter data laporan kasir
   <Frame>
     ![Input (19fewrwd)](/images/Input-\(19fewrwd\).png "Input (19fewrwd)")
   </Frame>
4. Pilih tanggal dengan range tertentu
   <Frame>
     ![Popover (4sdfsdfcc)](/images/popover-\(4sdfsdfcc\).png "Popover (4sdfsdfcc)")
   </Frame>
5. Setelah memilih tanggal, tekan tombol “Terapkan Periode”
6. Setelah menekan tombol maka akan menampilkan data sesuai tanggal di filter
7. Masukkan kata kunci tertentu di kolom cari untuk mencari data laporan kasir dengan cepat
   <Frame>
     ![Input (20ddfsdf)](/images/Input-\(20ddfsdf\).png "Input (20ddfsdf)")
   </Frame>
8. Tekan tombol "Nama Toko" untuk filter laporan kasir di toko tertentu
   <Frame>
     ![Inputfiltertoko](/images/Inputfiltertoko.png "Inputfiltertoko")
   </Frame>
9. Tekan tombol detail di salah satu list laporan kasir untuk melihat detail laporan kasir
   <Frame>
     ![Button (27werwerew)](/images/Button-\(27werwerew\).png "Button (27werwerew)")
   </Frame>
10. Setelah menekan tombol, maka akan menampilkan halaman detail laporan kasir
    <Frame>
      ![Dashboard (2werwssa)](/images/Dashboard-\(2werwssa\).jpg "Dashboard (2werwssa)")
    </Frame>
