## **1.1. Cara Melakukan Login Pertama Kali**

Anda dapat melakukan login pertama kali atau kondisi device anda belum tertaut untuk organisasi atau toko milik anda.

**Berikut merupakan tahapan login akun:**

1. Buka aplikasi Zycas dalam kondisi belum login, maka akan diarahkan ke halaman login
2. Masukkan no whatsapp anda dengan benar di kolom no whatsapp
   <Frame>
     ![Image 5](/images/image-5.png "Image 5")
   </Frame>
   Masukkan password anda dengan benar di kolom password
   <Frame>
     ![Image 6](/images/image-6.png "Image 6")
   </Frame>
3. Setelah selesai mengisi data login, kemudian tekan tombol “Masuk”
   <Frame>
     ![Button Masuk](/images/Button-Masuk.png "Button Masuk")
   </Frame>
4. Setelah menekan tombol, maka akan menampilkan halaman pilih toko dari list toko

<Frame>
  ![Pilih Toko](/images/Pilih-Toko.png "Pilih Toko")
</Frame>

| No | Simbol | Keterangan |
| :-- | :-- | :-- |
| 1 | Buat Toko | Tombol untuk membuat toko baru di organisasi |
| 2 | Cari Toko | Kolom untuk pencarian list toko |
| 3 | List Toko | Tombol untuk memilih toko saat login |
| 4 | Simpan dan Tautkan Device | Tombol untuk melanjutkan proses tautkan device |

5. Pilih salah satu toko yang anda miliki

<Frame>
  ![Frame 1410](/images/Frame-1410.png "Frame 1410")
</Frame>

6. Setelah selesai memilih toko, kemudian tekan tombol “Simpan dan Tautkan Device”

<Frame>
  ![Frame 1380](/images/Frame-1380.png "Frame 1380")
</Frame>

7. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi tautkan device

<Frame>
  ![Frame 1337 (1)](/images/Frame-1337-\(1\).png "Frame 1337 (1)")
</Frame>

8. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk melanjutkan proses login

<Frame>
  ![Image 21](/images/image-21.png "Image 21")
</Frame>

9. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan login

<Frame>
  ![Image 22](/images/image-22.png "Image 22")
</Frame>

10. Setelah menekan tombol “Ya, Saya Yakin”, maka akan menampilkan halaman pengisian OTP

<Frame>
  ![Image 23](/images/image-23.png "Image 23")
</Frame>

11. Masukkan kode otp sesuai dengan kode yang dikirimkan di no whatsapp anda

<Frame>
  ![Image 24](/images/image-24.png "Image 24")
</Frame>

12. Tekan tombol "Konfirmasi OTP"

![Image 25](/images/image-25.png "Image 25")

13. Setelah mengisi kode otp, jika kode otp benar, maka akan menampilkan pesan sukses dan diarahkan ke halaman enrollment

<Frame>
  ![Image 26](/images/image-26.png "Image 26")
</Frame>

14. Pilih salah satu akun untuk login di kolom pilih akun

![Image 27](/images/image-27.png "Image 27")

15. Masukkan password di kolom password

![Image 28](/images/image-28.png "Image 28")

16. Tekan tombol “Menuju Dashboard” di halaman detail device untuk diarahkan ke halaman dashboard Zycas

![Image 29](/images/image-29.png "Image 29")

## **1.2. Cara Membuat Toko**

Menu **Buat Toko** adalah menu yang berisi form untuk menambahkan toko baru. Untuk mengakses halaman ini adalah dengan klik Menu **Buat Toko** di halaman List Toko ketika login. Fitur ini sangat berguna jika anda memiliki lebih dari satu toko yang dikelola.

**Berikut merupakan tahapan membuat toko:**

1. Tekan tombol "Buat Toko" di halaman list toko setelah memilih organisasi ketika login
   <Frame>
     ![Frame 960](/images/Frame-960.png "Frame 960")
   </Frame>
2. Setelah menekan tombol maka akan menampilkan halaman form tambah toko
3. Masukkan nama toko di kolom nama toko
   <Frame>
     ![Image 8](/images/image-8.png "Image 8")
   </Frame>
4. Tekan tombol “Jenis Toko” untuk memilih jenis toko
   <Frame>
     ![Image 9](/images/image-9.png "Image 9")
   </Frame>
5. Setelah menekan tombol, maka akan menampilkan halaman list jenis toko
6. Pilih salah satu jenis toko
   <Frame>
     ![Image 11](/images/image-11.png "Image 11")
   </Frame>
7. Masukkan jenis toko lain di kolom jenis toko lain-lain  jika tidak tersedia pada pilihan
   <Frame>
     ![Image 12](/images/image-12.png "Image 12")
   </Frame>
8. Setelah selesai mengisi jenis toko lain-lain, kemudian tekan tombol “Pilih Jenis Lain-lain”
   <Frame>
     ![Image 13](/images/image-13.png "Image 13")
   </Frame>
9. Setelah selesai memilih jenis toko, maka akan menampilkan jenis toko di halaman buat toko
   <Frame>
     ![Image 14](/images/image-14.png "Image 14")
   </Frame>
10. Masukkan alamat toko di kolom alamat
    <Frame>
      ![Image 15](/images/image-15.png "Image 15")
    </Frame>
11. Checklist langsung pilih toko jika ingin menggunakan toko untuk login
    <Frame>
      ![Frame 12q9](/images/Frame-12q9.png "Frame 12q9")
    </Frame>
12. Setelah selesai mengisi data toko, kemudian tekan tombol “Simpan Toko”
    <Frame>
      ![Frame 1367](/images/Frame-1367.png "Frame 1367")
    </Frame>
13. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi simpan toko
    <Frame>
      ![Frame 13q36](/images/Frame-13q36.png "Frame 13q36")
    </Frame>
14. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk simpan toko
    <Frame>
      ![Image 21](/images/image-21.png "Image 21")
    </Frame>
15. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan simpan toko
    <Frame>
      ![Image 22](/images/image-22.png "Image 22")
    </Frame>
16. Setelah menekan tombol “Ya, Saya Yakin”, maka akan menampilkan pesan sukses membuat toko dan diarahkan ke halaman list toko
